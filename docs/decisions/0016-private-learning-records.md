# ADR 0016: 비공개 학습 기록과 기술 참조를 분리한다

- 상태: 승인·코드 반영 및 자동 검증 완료, 개발 DB 활성화 별도
- 기준일: 2026-09-07
- 상세 계약: [학습·서비스 연결](../superpowers/specs/2026-09-07-learning-service-link-design.md)
- 실행 계획: [비공개 Learning 1단계](../superpowers/plans/2026-09-07-private-learning.md)

## 결정

Platform Learning이 사용자 소유의 자유 메모와 구조화 실험을 저장한다. 기술 주제와 전문
도메인은 별도로 분류하고 RAG나 파인튜닝의 실행 결과를 학습 기록 안에서 생성하지 않는다.
2026-11-05 결정으로 비공개 기록은 현재 본문 한 건만 보존한다. 수정·보관·복원은 본문 교체와
동시 편집 토큰 갱신을 같은 트랜잭션에서 처리하며 이전 토큰을 사용한 쓰기는 409로 거부한다.
기존 버전 조회 주소와 버전에 고정된 참조는 현재 토큰에만 응답한다. 과거 본문은 0069 이관 때 삭제한다.
1단계 수명주기는 보관·복원이며 영구 삭제 API는 제공하지 않는다.

기술별 대상은 일반 참조 계약과 조립부 resolver로 연결한다. Platform에서 RAG 구현을
import하지 않으며 기록 소유권은 참조 대상의 권한을 추가하지 않는다. 연결·조회에서 현재
대상 권한을 확인한다. 비허용 대상의 제목·본문·링크는 반환하지 않는다.

비공개 API는 로그인 사용자의 소유 기록만 다루고 owner 역할에도 타인 기록 우회를 주지 않는다.
메모 본문은 우선 plain text로 표시해 HTML 실행·외부 이미지 자동 요청을 만들지 않는다.
공개 snapshot, 공개 캐릭터 연결, 모델 실행과 수동 학습은 별도 단계다.

### 평가 참조 표시 보완

같은 상태의 평가 실행을 사용자가 구분할 수 있도록 기존 소유자 전용 RAG 평가 응답에
저장된 `created_at`을 추가한다. DB의 기존 생성 시각을 전달하며 현재 시각이나 가짜 이름으로
대체하지 않는다. UI는 상태·생성 시각을 표시하고 동일 표시값의 목록 내 구분만 추가한다.
타인 실행 조회 정책, 평가 알고리즘·프로파일·DB 스키마는 변경하지 않는다. 식별 정보가 없는
임의 UUID 표시명이나 가짜 상세 경로를 만드는 대안은 사용하지 않는다.

## 결과

### 2026-11-05 출발점과 개선 요약

`learning_sequence`에 출발 유형 `start_mode`(base_model/continued/unknown), 출발 설명 `source_label`, 판단 근거 `source_evidence`, 개선 목표 `objective`, 결과 `outcome`, 남은 문제 `remaining`, 명시 판정 `outcome_status`(improved/no_improvement/mixed/not_evaluated)를 선택 정보로 보존한다. 이어 학습은 출발 설명이 필요하며 미기록·미평가를 성공이나 계승으로 추론하지 않는다. 출발 설명은 기록 당시의 스냅샷으로 일반 참조나 차수에서 만든 FK가 아니다. 기존 본문·평가·소유권 계약을 유지한다.

기본 화면은 `learning_latest`를 요청해 흐름별 실제 차수를 내림차순으로 보여준다. 기존 오름차순·수정일 정렬은 유지하며 전체 결과와 페이지 커서에 같은 정렬을 적용한다. 계획은 별도로 표시하고 평가 결과를 주장하지 않는다. [설계와 검증](../worklogs/2026-11-05-learning-lineage.md)을 따른다.

### 2026-11-05 학습 실행 순서

구조화 실험 JSON에 선택적인 `learning_sequence`(흐름 이름 `series`, 양의 차수 `step`, 실제 실행일 `performed_on`)를 보존한다. 기존 기록은 null로 호환하며 계획 상태에는 실제 차수·실행일을 넣지 않는다. 목록 응답에는 실험 상태와 이 정보를 전달하고 `learning_order` 정렬은 소유권·기존 필터를 적용한 전체 결과에서 흐름 이름과 실제 차수, 안정적인 동률 키 순으로 처리하며 관련 계획은 별도로 구분한다. 기존 수정일 정렬도 유지하며 커서는 정렬 계약을 구분한다.

이 정보는 명시적으로 작성한 실험 메타데이터다. 등록일·수정일·제목에서 실행 순서를 추론하거나 일반 참조를 어댑터 계승 관계로 바꾸지 않는다. DB 테이블 변경이나 자동 학습은 없다. 상세와 검증 기준은 [실행 순서 작업 기록](../worklogs/2026-11-05-learning-sequence.md)을 따른다.

- 기록은 여러 기술에 연결할 수 있지만 공개 여부와 서비스 준비 상태를 혼동하지 않는다.
- 현재 본문의 단일 보존·동시 수정·참조 권한 회수는 테스트 가능한 별도 계약이다.
- 기존 개인 자료를 자동 가져오기·공개·학습하지 않는다.
- 공개·외부 전송·훈련 승인 경계와 Codex CLI의 기존 차단 결정은 변경하지 않는다.
