## 새 질문 기록 형식

- ID / 발견 실제 날짜 / 연결 Day / 선수 개념 / 중요도(다음 학습 차단 여부)
- 사용자의 질문 또는 비식별 오답 요약 / 아직 설명 못한 지점
- 관련 코드·문서 / 보충 설명·합성 예제 / 시도 이력
- 다음 재검증일(실제 합의일) / 검증 질문 / 상태(진단 대기·열림·보충 중·재검증 대기·해결)
- 해결 근거 V-ID / 사용자 설명·전이 과제 / 다시 열릴 조건

다음 날에는 날짜가 오래된 질문보다 다음 개념을 막는 질문을 먼저 확인한다. 답변 생성만으로 해결 처리하지 않는다.

## 운영상 남은 확인

- 하루 가용 시간과 기존 Python/SQL/선형대수 숙련도는 Day01 진단에서 확인한다.
- 실제 설치·유료 API·모델 다운로드·학습·클러스터 실습은 아직 승인되지 않았다. 날짜 도래만으로 실행하지 않는다.
- 사용자 마지막 요청이 학습 관리 구조에서 끊긴 뒤의 추가 요구는 추정하지 않았다.
