# Mermaid 실행 흐름도와 단계 상세 모달

- 날짜: 2026-10-24
- 관련 문제: ISSUE-00035
- 사용자 요청: Mermaid로 전환하고 연결된 단계를 자유롭게 옮기며 클릭 시 지침·입력·결과 모달을 표시한다.
- 설계: [표시·조작·보관 경계](../superpowers/specs/2026-10-24-mermaid-agent-monitor-design.md)
- 계획: [구현·검증 역할과 순서](../superpowers/plans/2026-10-24-mermaid-agent-monitor.md)

## 적용한 동작

실제 Mermaid SVG로 모든 agent/model/delegation/tool 단계를 표시한다. 간선은 저장된 부모 관계만 사용한다. 기록 번호를 실행 순서 간선으로 만들거나 중간 모델 호출·위임을 생략하지 않는다. 실제 기존 기록은 5개 노드와 4개 부모 연결이다.

노드 드래그와 연결선 갱신, 빈 공간 드래그로 화면 이동, 확대·축소, 전체 보기, 배치 초기화를 제공한다. 클릭 또는 Enter/Space는 정확한 단계 ID의 모달을 연다. Tab으로 선택하고 방향키로 이동하며 Shift를 함께 누르면 크게 이동한다. 같은 실행의 상태 갱신과 모달 열기/닫기에도 배치·보기 위치를 유지한다. 다른 실행 또는 페이지 재방문 시 초기화하며 DB/localStorage에 위치를 저장하지 않는다.

모달은 지침/입력과 관측 반환값을 나란히 비교하고 좁은 화면에서는 세로로 표시한다. 실제 JSON 필드를 질문, 재작성 질의, 대화 이력, 검색 근거, 메시지 역할, 답변 주장, 도구 인자로 나눈다. 원문과 길이/SHA는 펼쳐 본다. 알려지지 않은 필드는 원문에 있다는 안내를 유지하며 깊거나 큰 구조에는 표시 한도를 둔다. 새 LLM 요약을 만들지 않는다.

retained/current 및 미수집·미보관·해당 없음·검증 실패 숨김·크기 초과 상태를 그대로 적용한다. 표시 권한 판정 전에 본문을 파싱하지 않으며 숨겨야 할 본문은 DOM에도 넣지 않는다. Escape·닫기·배경 클릭, 모달 안 Tab 순환, 배경 inert/스크롤 잠금, 호출 노드로 포커스 복귀를 지원한다. 과거 영어 지침은 당시 원문으로 보존한다.

## 의존성과 안전한 렌더링

공식 `@mermaid-js/tiny@12.2.0` 한 패키지만 고정 추가했다. registry의 압축 해제 크기는 2,814,338바이트이며 일반 Mermaid 12.2.0의 122,322,316바이트 대신 필요한 흐름도 렌더러만 사용한다. 기존 패키지 일괄 갱신, 모델 설치·다운로드와 별도 그래프 라이브러리 추가는 없다.

Tiny 배포는 classic script이므로 Next가 내보내는 같은 출처의 정적 자산으로 로드한다. CDN이나 외부 렌더링 서비스에 실행 내용을 전송하지 않는다. `securityLevel: strict`, 루트/flowchart `htmlLabels: false`를 유지한다. ID는 내부 순번이며 이름의 문법 구분 문자는 표시용 전각으로 바꾼다. 정확한 저장 이름은 접근성 이름과 모달에서 유지한다. 통제된 줄바꿈 외 데이터의 Mermaid 지시문/HTML/콜백을 실행하지 않는다.

참고: [Mermaid 사용 문서](https://mermaid.js.org/config/usage.html), [flowchart 문법](https://mermaid.js.org/syntax/flowchart.html).

## 구현 중 확인하고 수정한 경계

- 실제 Mermaid 12 SVG ID는 렌더별 접두사를 포함했다. 이 ID에 맞춰 노드와 간선 연결을 수정하고 namespace 회귀를 추가했다.
- 숫자 HTML entity 전체 인코딩은 SVG 텍스트에 그대로 보였다. 한글을 유지하고 위험한 문법 문자만 표시용으로 치환하도록 수정했다.
- 실제 SVG pointer capture는 클릭 대상을 SVG로 바꿨다. 이동 없는 pointerup에서 원래 노드를 선택하고 뒤따르는 호환 click을 한 번 소비해 클릭 실패/이중 열기를 방지했다. 드래그와 pointercancel 회귀도 유지한다.
- 독립 검토에서 같은 실행을 다시 그리는 중 이전 ready/error 표시가 남는 문제를 재현했다. 현재 source 기준으로 loading을 판정하고 오래된 결과를 버린다. 렌더 시도마다 ID도 분리한다.
- 렌더러 initialize 예외로 로딩 Promise가 끝나지 않는 문제를 독립 재현했다. 일반 실패로 reject하고 재시도 가능한 상태로 정리한다. 실패 시 전체 단계 목록의 상세 조회는 유지한다.
- 기존 대화 진단 테스트의 하단 상시 상세 기대값은 클릭 후 portal 모달 계약으로 이관한다. 본문 보관·검증 실패 숨김·원문 링크 보장은 유지한다.

## 검증

- 실제 Mermaid 5개 노드·4개 부모 간선, SVG script/foreignObject 0.
- 실제 마우스 드래그 후 노드 좌표와 연결된 2개 간선 변경, 무관한 간선 불변, 모달 0개.

- 1280×900, 약375×800, 320×800 CSS px에서 실제 렌더된 모달/컨트롤 좌표 확인. 320px 모달 폭304px·가로 넘침0, 버튼 높이44px. 브라우저의 기존75% 배율을 보존한 채 viewport 입력을 조절했으며 검사 뒤 override를 해제했다. 좁은 화면은 확대/이동 또는 전체 단계 목록으로 확인할 수 있다.
- viewport override 중 CDP 스크린샷2회가 timeout되어 이를 제품 실패로 분류하지 않았다. DOM 크기 검사를 완료하고 기본 크기로 복구한 뒤 정상 흐름도/모달 캡처를 저장했다.
- 합성 단위 테스트와 본래 환경의 저장된 공개 합성 자료 확인을 구분한다. 실제 터치 장치/새 실행 중 갱신/모바일 전체 업무 E2E는 주장하지 않는다.

## 보존과 남은 범위

기존155개 변경 파일은148개 SHA 동일·허용된 UI/WORKBOARD 7개 변경·누락0으로 확인했다. 관련 없는 사용자 변경과 과거 문제 문서·검증 결과는 보존한다. 신규 생성·임베딩0, 서비스 재시작0, RAG 운영 DB/프로파일 변경0, commit/push0이다. 인증된 문제 관리 화면의 ISSUE-00035 진행 이력/문서 등록만 별도로 갱신한다.

인증된 관리자 화면에서 ISSUE-00035 수정·검증·남은 범위, 2026-10-24 진행 이력, 문서 `59aa7b26-1e18-4a93-b8dc-fefe1e7a84d5` 버전1 연결을 저장하고 조회로 확인했다. 문서 등록의 첫 자동 승인 검토는 정확한 등록 권한 근거 부족으로 거절됐다. 사용자 제공 AGENTS의 문제 이력 갱신 지시와 `docs/issues/README.md`의 인증된 관리 화면·정확한 문서 버전 연결 규칙을 확인한 뒤 같은 정상 화면에서 승인되어 저장했다. 우회 경로나 직접 DB 수정은 사용하지 않았다.

이 작업은 흐름도 조작과 단계 상세 표시 개선이다. 기존 RAG 품질 실패, 평가 예산, 도메인/일반 대화 활성화 상태는 바꾸지 않는다. 대화 턴 선택, 실제 채택/제외 문맥·문맥화 입력/결과 관측, 일반 대화 수집 경로와 실제 멀티턴 검증은 [앞선 점검](2026-10-24-monitoring-multiturn-audit.md)의 후속으로 남긴다. 현재 표시 개선을 이 후속의 완료로 확대하지 않는다.
