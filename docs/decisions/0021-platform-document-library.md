# ADR-0021: Platform 문서 라이브러리와 독립 원문 열람

- 상태: 승인됨(2026-09-09 사용자 단계별 진행 승인)
- 정본: [상세 설계](../superpowers/specs/2026-09-09-document-library-design.md)

문서 탐색·폴더·원본 버전 열람은 Platform Assets의 책임이다. 검색 색인과 projection을
요구하는 RAG 근거 뷰어를 파일 관리의 필수 경로로 사용하지 않는다. 열람은 공간 접근권한,
원본 READY와 정확한 버전/바이트 무결성을 확인하며 외부 모델이나 OCR을 호출하지 않는다.

첫 구현은 폴더 조회/생성/업로드, 회사·개인 구분과 TXT/Markdown/PDF 직접 열람이다.
Office 미리보기·이동·휴지통·외부 AI 정책/승인 관리 위치 변경은 별도 후속 단계다.
기존 원본·문서 버전·승인 상태는 변경하지 않는다. 전체 RAG 검증 완료와 구별한다.
