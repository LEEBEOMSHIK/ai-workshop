# 자산운용 합성 PDF 검증

- 날짜: 2026-09-27
- 상태: PDF 제작·독립 내용/시각 검증·앱 PDF 파서 검증 완료. 실제 브라우저 업로드는 확장 프로그램의 파일 접근 설정 대기.
- 범위: 상품 설명서, 월간 운용보고서, 업무 지침서와 별도 평가 정답표

## 목적과 성공 기준

단일 지급일 문구에 맞춘 예제 대신 자산운용 업무의 문맥, 표, 조건과 예외를 검색할 수 있는 합성 자료를 만든다.
회사·상품·수치·절차는 모두 가상이며 실제 고객 자료를 사용하지 않는다.
문서끼리 기준일, 상품 식별자와 조건을 일관되게 유지한다.
정답표에는 질문 유형, 기대 답변, 근거 파일과 페이지를 기록하며 검색 대상에는 업로드하지 않는다.

## 검증 구분

1. PDF 품질: 모든 페이지 렌더링, 한글·표·각주·여백과 텍스트 추출 확인.
2. 내용 품질: 수치와 조건의 문서 간 일관성, 정답표 근거 페이지 독립 확인.
3. 수집: 기존 RAG 합성 참조 자료 공간에서 원본 READY와 해당 검색 프로파일의 RAG 준비 상태 확인.
4. 실제 대화: 기존 로그인·도메인에서 문서 선택과 질문 전송, 근거·유사도·소요 시간 확인.
5. 결과 보존: 성공, 오답, 근거 부족, 실행 실패와 미실행을 구분하며 실제 브라우저 검증과 내부 검증을 혼동하지 않는다.

스캔/OCR 품질은 이번 텍스트 PDF 검증과 구분한다. 별도 환경·DB·계정은 만들지 않는다.
생성된 PDF와 정답표는 로컬 산출물로 보존하고 재현 가능한 생성 소스와 검증 기록을 Git에 남긴다.

## 산출물과 검증 결과

- `output/pdf/synthetic-product-prospectus.pdf`: 3쪽, 상품·환매 조건과 예외·보수·위험.
- `output/pdf/synthetic-monthly-report.pdf`: 3쪽, 성과·자산 배분·발행사 집중도·미해소 상태.
- `output/pdf/synthetic-operations-guidelines.pdf`: 3쪽, 한도·보고·해소·누락 자료 처리.
- `output/pdf/EVALUATION-ONLY-answer-key.json` 및 `.md`: 평가 전용 16문항, 업로드 금지.
- 생성기: `scripts/build_asset_management_corpus.py`. PyMuPDF·Pillow와 한글 폰트를 사용한다.

9페이지 전체 렌더링과 주요 표 페이지 확대 검토에서 한글 깨짐·표 잘림·내용 넘침이 없었다.
글꼴 부분 임베딩으로 PDF 3종 합계 약611KB이며 각 문서의 SHA-256을 정답 JSON에 기록했다.
독립 검증에서 자산 배분 합계, 총보수 합계, 초과 수익률의 %p, 가정된 영업일 계산이 일치했다.
앱의 실제 `PdfParser`를 로컬 파일에 적용해 각각100/97/87개 요소와 페이지·bbox 위치를 확인했다.
최종 정답표의25개 근거 인용이 지정된 파일·페이지에서 추출됐다. 이는 수집·색인·생성 성공을 뜻하지 않는다.

## 실제 환경 검증의 중단 지점

기존 마스터 계정으로 자산운용 파일함의 `RAG 합성 참조 자료` 공간까지 접근했다.
상품 설명서 업로드의 파일 선택 단계에서 Chrome 확장 프로그램이 `Not allowed`를 반환했다.
도구 안내에 따라 ChatGPT 확장의 `파일 URL에 대한 액세스 허용` 설정을 사용자에게 요청했다.
업로드 완료·색인 준비·실제 대화 답변 검증은 아직 수행하지 못했으며 성공으로 보고하지 않는다.
파일 접근 설정 완료 후 PDF 세 개만 업로드하고 정확한 합성 문서 버전 승인과 실제 질문 검증을 이어간다.
