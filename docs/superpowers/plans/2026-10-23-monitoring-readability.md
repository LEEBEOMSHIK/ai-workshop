# 실행 모니터링 가독성 개선 Implementation Plan

**Goal:** 실행 결과와 실제 에이전트 위임을 요약·연결 구조로 읽도록 개선한다.

**Architecture:** 기존 React 컴포넌트와 CSS Module만 변경한다. 관측 데이터·권한·모델 실행은 그대로 두고 상세 정보의 우선순위를 바꾼다.

**Tech Stack:** React, TypeScript, CSS Modules, Vitest/Testing Library, 기존 CUA 브라우저.

**Spec:** [표시 설계](../specs/2026-10-23-monitoring-readability-design.md).

## 공통 제약과 역할

- 메인: 요구/수용 기준, 실행 요약·처리 시간 표시, 기존 브라우저, 문서·통합.
- 프론트엔드 담당: AgentTracePanel·CSS·그 회귀/합성 fixture. 메인 파일과 수정 경계를 분리한다.
- 독립 통합 검증: 본문 비노출·기존 실행 전환·상태·키보드 계약과 관련 UI 회귀를 검증한다. 제품 코드를 수정하지 않는다.
- 백엔드·DB·AI 런타임·배포는 이번에 변경하지 않아 제외한다. 실제 모델 예산4/4 소진 상태를 유지한다.

## 검토 초점

- 부모 순서가 바뀌거나 분기가 여러 개인 trace: 실제 부모만 연결한다.
- 모델 토큰이 누락된 경우: 미보고를0으로 치환하지 않는다.
- 완료와 품질 실패가 함께 있는 실행: 각각의 의미를 유지한다.
- 실행 ID가 바뀌는 중: 이전 선택·본문·원문이 잔류하지 않는다.
- 좁은 폭·긴 한글/식별자: 가로 넘침과 포커스 잘림 없이 선택 가능하다.
