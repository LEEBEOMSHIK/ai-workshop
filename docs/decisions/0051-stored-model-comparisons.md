# ADR-0051: 저장된 모델 비교의 비공개 조회

- 상태: 구현·본래 DB/API 반영·인증된 실제 수입 수용 완료
- 날짜: 2026-10-29
- 근거: 사용자가 기존 OpenAI/Gemma 비교 결과·분석을 평가·실행 화면에서 조회하도록 요청했다.

## 문제

진단 실행기의 완료된 비교는 파일에만 있어 제품 화면에서 조회할 수 없다. 기존 생성형 평가와 실행은 데이터셋·정책·구성·worker 및 승격 게이트에 연결되므로 외부 완료 기록을 해당 실행으로 꾸며 넣으면 실제 수행 범위를 왜곡한다.

## 결정

Labs/RAG의 별도 `comparisons` 모듈이 불변 비교 보고서를 소유한다. additive `rag_comparison_reports` 테이블에 소유자, 수입 키, 원본 SHA, 서버 계산 내용 digest, 실제 완료시각/수입시각 및 검증한 구조화 본문을 저장한다. 자료는 기본 비공개이며 공개 reader에는 연결하지 않는다.

관리자 소유자 인증 아래 수입·목록·상세 API를 제공한다. 같은 소유자/수입 키와 같은 내용은 무변경 재사용하고 변경 내용은409로 거절한다. 수입은 추론·검색·worker 접수·프로파일 변경을 호출하지 않는다. 원본 SHA는 출처 식별자이며 서버가 실제 모델 실행을 인증했다는 뜻이 아니다.

수입과 조회에서 소유권, 현재 workspace 읽기 권한, 정확한 document/version/projection/index 관계·문서 활성·READY를 검사한다. 인용 원문의 evidence ID/본문/위치/관계를 실제 저장 단위와 대조한다. 권한이 없어진 보고서는 목록에서 제외하고 상세는404로 처리한다. private 응답은 no-store다.

본문은 타입과 크기가 제한된 allowlist다. 질문·모델별 완료 응답·요청 시간·선택적 native 단계·토큰·Decimal 비용·실제 답변·인용·항목별 수동 품질 검토·분석·한계를 포함한다. 원시 provider 응답, 응답 식별자, 계정 잔액, 자격 증명은 계약에 넣지 않는다. 미측정/null과 실제0, 예상 비용과 청구 확인액을 구분한다.

평가 화면의 ‘저장된 모델 비교’ 및 실행 화면의 별도 진입점이 같은 상세를 연다. 기존 실행 건수·통계·품질 게이트에 합산하지 않는다. 기존 원문뷰어를 현재 권한 아래 재사용하고 원문 참조를 임의 URL로 가져오지 않는다.

## 대안과 영향

- 일반 실행으로 이관: 검색/실행·승격의 의미를 왜곡하므로 제외한다.
- 보고서를 정적 공개 파일로 제공: 비공개 경계·현재 원문 권한을 적용할 수 없어 제외한다.
- 별도 구조화 기록: 새 테이블/계약이 필요하지만 기존 생성 품질과 실행 흐름을 바꾸지 않고 목적을 충족한다.

이는 저장 관측의 조회 기능이다. 수입된 형식·인용 검사와 사람의 의미 검토를 표시하며 제품이 새 실모델 평가를 수행했다고 표현하지 않는다. 상세 설계와 수용 기준은 [설계](../superpowers/specs/2026-10-29-stored-model-comparisons-design.md)를 따른다.
