# 공개 연구 기록 탐색·세부 위계 보완

## 승인 범위

사용자 피드백에 따라 Publishing 화면의 상단 nav 표면·메뉴 버튼·간격, 상세 소제목과
본문 위계, 실제 `기록 읽기` 링크를 보완한다. 기존 공개 내용·권한·API·DB는 유지한다.
main에서 프론트/TDD 담당, 메인 통합 검증, 독립 리뷰의 책임을 분리한다.

## 원인과 표현 계약

- 기록 읽기는 aria-hidden span이어서 버튼처럼 보여도 동작하지 않았다. 제목 링크를
  유지하고 읽기 문구도 동일 상세 URL의 접근 가능한 링크로 제공한다. eager prefetch는 없다.
- 이전 nav 변경은 링크 대비에 그쳤다. Publishing 범위에 표면·테두리·여백·메뉴 버튼의
  상태 스타일을 적용하며 다른 공개 화면의 공통 nav를 임의로 재설계하지 않는다.
- 공개 본문은 빈 줄로 구분된 블록의 첫 줄에 기존 소제목이 있는 일반 텍스트다.
  기존 편집본의 명시적인 소제목 어휘를 표시 호환 규칙으로 분리한다. 여러 줄 블록의
  첫 줄이 정확히 일치할 때만 h3와 본문으로 나누고 나머지는 그대로 문단으로 표시한다.
  이는 새 도메인의 제목을 제한하는 업무 규칙이 아니며 일반 문장을 길이로 추측하지 않는다.
  Markdown/HTML은 해석하지 않고 React 이스케이프를 유지한다. 관리자 미리보기도
  같은 StudyBody를 사용한다. 향후 자유로운 제목 편집은 명시적 구조 계약으로 확장한다.

## 검증

- 변경 전 실제 Edge 1440/960/390에서 읽기 링크 부재·nav 표면 부재·소제목 부재 9건 재현.
- TDD: 새 수용 테스트 3건 실패를 확인한 뒤 구현했다. 마지막 Publishing 35개 테스트가
  통과했다(5개 파일, 28.05초). 전체 ESLint와 TypeScript 통과.
- 실제 Edge 1440/960/390에서 읽기 링크 마우스 클릭·Enter 진입, 제목 진입·목록 복귀,
  nav 표면·소제목 시각 위계·가로 넘침 없음을 확인했다. 공개 기록 15건 전체의 소제목과
  본문을 대조했고 전후 공개 API 응답은 동일했다. 브라우저 최종 issues는 0건이다.
- production build 종료 0. 기존 publishing-build 캐시를 재사용했고 Next가 추가한
  테스트 인스턴스 타입 경로만 원복한 뒤 TypeScript를 다시 통과했다.
- 독립 리뷰는 변경 6개 파일을 작업 전 사본과 대조했다. 차단/중요 결함 없음.
  prefetch 검증은 기존 테스트의 data 속성 한계가 있어 실제 Link의 false 설정도 검토했다.
- 실제 관리자 로그인/편집은 하지 않았다. 공용 StudyBody와 관리자 미리보기 회귀 테스트로
  일치를 확인했다. 사용자 데이터·게시 상태·서버는 변경하지 않았다. 캐시 삭제·커밋·push 없음.
