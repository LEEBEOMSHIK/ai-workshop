# ADR-0007: 공개 RAG 상세를 담당 에이전트 작업실로 구성한다

- 상태: 승인됨
- 결정일: 2026-09-04
- 대체 범위: `ADR-0006`의 공개 입구 캐릭터 첫 목적지

## 배경

공개 입구의 RAG 총괄을 선택해도 `/labs`를 한 번 더 거쳐야 하고, `/labs/rag`는 정적 기술
목록만 보여준다. 이 흐름은 총괄이 담당 연구실로 안내하고 연구실 안의 담당자들이 각 공정을
설명한다는 제품 의도를 충족하지 못한다.

## 결정

공개 입구의 전체 보기 링크는 `/labs`로 유지하되 RAG 총괄 캐릭터의 CTA는 공개 catalog가
소유한 `/labs/rag`로 직접 연결한다.

`/labs/rag`는 RAG 총괄과 현재 구현된 여섯 기술 담당자가 파이프라인 작업대에서 일하는
DOM·CSS 기반 연구실로 구성한다. 담당자 콘텐츠는 별도 검증된 registry에서 읽으며 선택 시
기존 접근 가능한 연결 말풍선으로 역할과 인계 흐름을 설명한다. 미구현 Generation과
Reranker는 활동 중인 담당자로 노출하지 않는다.

캐릭터는 사용자 설명 계층이다. 실제 파싱·색인·검색 실행이 모두 LLM 에이전트라는 의미로
사용하지 않으며, 결정적 서비스 worker와 판단형 LLM 후보의 경계는 RAG 설계를 따른다.

## 결과

### 장점

- 입구에서 관심 Lab으로 직접 이동하면서 전체 Lab 탐색 경로도 유지한다.
- RAG 내부 계층과 문서 처리 흐름을 정적 목록보다 공간적으로 이해할 수 있다.
- 작업자 콘텐츠를 컴포넌트와 분리해 실제 기능 추가 시 검증된 registry로 확장할 수 있다.

### 비용

- 공개 작업자 registry 검증과 여섯 캐릭터의 반응형·접근성 회귀 검사가 필요하다.
- 실제 구현 범위가 바뀌면 공개 작업자 구성과 설명도 같은 변경에서 갱신해야 한다.
