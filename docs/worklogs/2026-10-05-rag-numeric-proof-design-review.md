## 이번 진행과 확인

현재 인용 검증·프로파일·Codex wire/프롬프트·provider·비공개 평가 결과·DB0059 승인 경로를
읽고, Q08/Q12의 고정 QA·formal rule과 승인된 합성 자료의 필요한 원문만 본래 DB에서 대조했다.
원문·질문·답변·계정·비밀을 이 보고서에 복사하지 않았다. SQL은 읽기 전용·rollback으로 실행했다.

Q08/Q12의 formal rule은 answered·필수 근거그룹2·required_propositions=[]다. QA의 정답문을
formal 명제 규칙으로 잘못 옮기지 않았다. 과거 성공한 Q12 exact claim의 제한된 원문 대조는
직접 날짜 지원 경로가 있음을 확인하는 용도이며, 실패 초안을 소급 채우는 자료가 아니다.

## 권고 계약

새 불변 생성 프로파일과 schema3에서 모델은 서버가 제공한 원문 숫자 토큰 ID, 제한된 연산과
주장 결과 위치만 제출한다. 서버는 같은 주장에 직접 인용한 현재 허용 원문으로 Decimal을
재계산한다. 첫 연산은 부호 있는 퍼센트포인트 차이와 원/만원/억원의 정확한 단위 환산이다.
반올림·환율·연산 사슬·날짜 추론은 지원하지 않는다. 날짜는 기존 직접 값 검증을 유지한다.

원문 문맥이 별도 문단에 존재해도 구조적 관계가 없는 단위 없는 숫자는 첫 token catalogue에
넣지 않는다. 표 관계 보강은 별도 parser/provenance 작업이며 새 source snapshot·색인 호환성을
확인해야 한다. 생성 프로파일만 바꾸면 Q08까지 해결된다고 보고하지 않는다.

기존 schema1/2·프로파일·JSON/digest·판정은 그대로 유지한다. 신규 성공한 계산에만 검증된
출처와 연산을 비공개 저장하고 DB 승인 경로는 기존 citation_valid 하나만으로 계산 검증 완료를
인정하지 않는다. 계산 성공과 상품·시점·질문의 의미 판단을 분리하며 독립 원문 의미 평가를 유지한다.

## 독립 검토와 조사 정정

요구·AI 담당의 계약 후보와 독립 privacy/security 담당의 원문 진단·명세 검토를 분리했다.
독립 검토에서 ADR의 최초 ‘비율 차이3’를 실제 관측인 ‘퍼센트포인트3’로 정정했다. 관측은
종류·개수만 확인하며 연산을 확인하지 않았다는 경계를 추가했다. schema3 위치 보존을 위해
text==text.strip()을 요구하고 Decimal 반올림 오류와 DB0059의 승인 계약 누락을 명세에 보강했다.

조사 helper의 한국어 검색 literal이 PowerShell 작성 중 손상되어 나온 최초 헤더0 통계는
철회했다. Unicode escape와6개 검색어 guard를 적용해 읽기 전용 재조회한 뒤 별도 단위/헤더/행
문단 존재를 확인했다. 손상된 통계를 제품 원인으로 사용하지 않았고 최초·정정 기록을 구분해
보존했다. paragraph/table_cell=null과 동결 payload의 관계 필드 부재는 독립된 ID/구조 검사다.

## 검증·보존·남은 작업

역할 계약 검사 exit0, 새 문서3개의 로컬 링크11개·미완성 표기·기본 비밀 패턴 검사와 WORKBOARD
최근 완료5개 검사를 통과했다. 관련 tracked 문서의 git diff --check도 exit0이다.
제품 코드 변경이 없으므로 제품 테스트를 재실행해 구현 통과로
보고하지 않는다. 독립 검증은 기존 보고서7개의 파일/DB exact SHA·v1·연결 및 첫75/68판정/새7의
전체 열 동결값을 읽기 전용으로 대조해 보존을 확인했다.

본래 계정·문서·DB0061·서버·모델·색인·활성 연결·엄격한 정책과 후보 pending/defaultfalse를
유지했다. 새 모델 호출·평가 재시도·DB 구조 변경·서버 재시작·별칭 해제·commit/push는 하지 않았다.
이 보고서 작성 후 정상 관리자 API로 정확한 v1을 기존 문제에 추가 연결한다. 그 결과는 별도
등록 receipt에서 확인하며 과거 사건·문서 링크를 보존한다. 파일 경로만 기록해 DB 연결을 대신하지 않는다.

독립 검증·본래 환경의 새 프로파일 평가다. Q08 구조 보강과 Q12 상세 실패 진단도 남아 있다.
