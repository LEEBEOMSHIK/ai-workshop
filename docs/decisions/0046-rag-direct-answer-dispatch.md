# ADR-0046: 선택형 답변 담당 직접 실행

- 날짜: 2026-10-26
- 상태: 사용자 요청 범위 구현 결정, 실제 품질·속도 수용 전
- 관련: [ADR-0039](0039-rag-agents-sdk-monitoring.md), [ADR-0044](0044-rag-reference-evidence-input.md)

## 근거와 결정

사용자는 현재 답변 품질을 유지하며 첫 응답 속도를 개선하도록 요청했다. 직전 비기본 v6 실행 `cc82e756-b56b-44c1-951d-b7c4174e6178`의 첫 전체 시간은210.948초, 답변 담당 입력 처리는134.925초다. 추가 무손실 입력 사전화는 새 설명 전 최대61바이트만 절약해 채택하지 않는다. 실행 옵션 조정은 현재 실효값·개선 효과가 확인되지 않아 이번 변경에서 제외한다.

같은 실행의 두 관리자 반환 작업은 원질문·resolved_query와 정확히 같다. 관리자는 새로운 근거나 정보를 추가하지 않았다. 첫 관리자 HTTP26.046초 중 로드13.331초, 입력9.783초, 출력2.440초이며 반복은3.526초였다. 로드는 답변 담당으로 옮겨갈 수 있으므로 관리자 호출 전체를 순절감으로 계산하지 않는다.

버전 고정 생성 프로파일의 `orchestration.dispatch_mode`에 `manager_delegation`(생략 시 기존값)과 `direct_answer`를 허용한다. 후자는 애플리케이션이 원질문을 작업으로 지정하고 실제 Agents SDK Runner로 답변 담당을 한 번 실행한다. 일반 기본값과 기존 프로파일을 바꾸지 않는다. 조정 모델이 다른 의미의 작업을 만드는 경우까지 동등하다고 주장하지 않는다.

## 입력·실행 계약

- 동일한 답변 담당 Agent, 지침, 모델, schema2, v6 참조 매핑, 원질문·resolved_query·선택 이력·근거를 사용한다. 공통 입력 조립기에 `delegated_task=request.question`을 전달한다. 기존 관리자 반환이 원질문과 같은 경우 실제 specialist HTTP 요청 바이트가 같아야 한다.
- 관리자를 실행한 것처럼 표시하거나 가짜 위임·모델 span을 만들지 않는다. 직접 경로는 답변 담당 agent와 그 model 두 span을 실제 hook/transport로 수집한다. 모드 선택은 프로파일 설정 스냅샷에 남는다. 기존 비공개 본문 저장·현재 ACL·인용 검증을 유지한다.
- 직접 경로는 생성 모델1회/도구0회, 기존 위임은 모델2회/도구1회다. `max_tool_calls=1`은 기존 정책의 상한으로 유지하며 직접 경로에서 사용하지 않는다. 선행 문맥화 호출과 출력 예약량은 어느 경로에서도 총예산에 합산한다.
- 재시도0, 같은 로컬 배포, 외부 전송·추론 저장 금지, timeout·취소·종료 미확인·권한 재확인 계약을 유지한다. 직접 경로 실패 시 관리자나 다른 모델로 전환하지 않는다.
- 모델·원문·선택 근거·출력 제한·배치/스레드 설정을 함께 바꾸지 않는다. 장문 원질문은 기존 세대 입력 계약을 따르며 관리자의 도구 인자 길이 제한을 새로 강제하지 않는다.

## 수용 경계

오프라인 검증은 실제 SDK+MockTransport를 사용해 직접 경로 한 호출/두 span, 기존 경로 두 호출/다섯 span, 입력 바이트·28근거·위치·인용 매핑 보존, 선행 문맥화 예산, ACL 거부, 잘못된 반환·취소·timeout을 확인한다. DB 스냅샷 및 현재 UI가 두 span을 추정 없이 읽는지 확인한다.

실제 검증 후보는 기존 v6를 복제한 draft·비기본 프로파일에서 dispatch_mode만 바꾼다. 같은 공개 질문 두 반복과 기존16MiB claim 재사용 조건을 사용한다. 새 호출 예산을 받은 뒤 최대2회(반복별 직접 생성1회), 재시도0으로 실행하고 입력·답변·인용·품질 항목과 총시간·로드·prefill·decode를 비교한다. 모델의 수치 연산·캐시 상태까지 동일하다는 보장은 없으므로 무손실 입력만으로 답변 품질 통과를 선언하지 않는다. 기존 품질0/2는 별도 결함이며 추가 퇴행 여부와 구분한다. 실제 검증 전 일반 기본값으로 승격하지 않는다.
