# ADR-0023: 도메인 중심 파일함과 대화

- 상태: 사용자 상세 계약 승인(2026-09-10), 1단계 코드 구현·자동 검증·실행 서버 반영 완료, 로그인된 실제 화면 검증 대기
- 정본: [도메인 파일함·대화 설계](../superpowers/specs/2026-09-10-domain-cabinet-conversation-design.md)
- 후속 승인(2026-09-13, 단계별 구현 중): [통합 파일함과 대화 범위](../superpowers/specs/2026-09-13-unified-cabinet-design.md)

사용자는 도메인을 먼저 선택하고 그 안에서 회사·개인 파일함과 대화를 이용한다.
문서를 먼저 고른 뒤 도메인을 선택하는 이전 제안은 채택하지 않는다.
파일함 방문·파일 선택·미리보기는 대화의 필수 선행 순서가 아니다. 도메인 대화에서
공간, 폴더 또는 개별 파일을 검색 범위로 선택할 수 있으며 탐색과 미리보기만으로 범위가 변하지 않는다.
독립 파일함은 유지하되 같은 탐색·관리 컴포넌트를 대화의 선택적 패널에서도 재사용한다.
이 후속 결정은 대화 내 파일 관리 통합을 일괄 제외했던 이전 결정을 대체한다.
관리 기능은 서버의 쓰기 권한·동시 변경·휴지통 정합성 계약을 갖춘 순서대로 제공한다.

2026-09-13 사용자 승인한 [전사 구성원 권한](../superpowers/specs/2026-09-13-workspace-member-permissions-design.md)은
시스템 마스터와 workspace OWNER를 분리한다. 신규/기존 구분은 최초 기본값에만 쓰며 현재 소유자가 부여한 권한을 적용한다.
권한 저장·감사·동시 변경 및 실제 읽기/쓰기 검사를 함께 검증한 뒤 관리 화면에 연결한다.

Platform의 원본·권한 소유권은 유지하고 RAG가 도메인 맥락과 검색 연결을 소유한다.
기존 공통 파일함 주소는 보존한다. 문서 선택은 실제 검색 이전 제한과 대화 문맥 검증까지 연결하며,
대화 첨부는 별도의 사용자·대화 소유권 및 만료 계약이 필요하다.
개인·임시 자료를 전사 허용 공간에 자동 추가하거나 외부 전송 승인으로 간주하지 않는다.

도메인 파일함/선택 검색을 먼저, 개인·임시 입력 확장을 다음 단계로 구현한다.
ADR-0021의 독립 원문 열람과 기존 도메인 권한 교집합을 폐기하지 않고 확장한다.
