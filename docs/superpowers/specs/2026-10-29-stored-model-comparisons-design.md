# 저장된 모델 비교 조회 설계

2026-10-29. 사용자는 기존 OpenAI/Gemma4회 비교의 속도·답변·인용·품질·usage/cost·분석을 사이트 평가·실행에서 함께 확인하고 기존 기능과 답변 품질을 유지하도록 요청했다. 본 설계의 화면/저장 세부는 이 요청을 충족하기 위한 구현 판단이다. [ADR-0051](../../decisions/0051-stored-model-comparisons.md)을 따른다.

## 범위와 접근

선택한 접근은 별도 비공개 비교 기록과 공유 상세 화면이다. 기존 생성형 평가에 가짜 실행을 삽입하는 방법은 구성 승격/worker 상태와 섞이므로 제외한다. Markdown을 정적 제공하는 방법은 권한·구조화 비교와 데이터 보존 요구를 충족하지 못한다. 새로운 추론/재평가·모델 설정·색인·프롬프트 변경은 하지 않는다.

## 저장과 API

- `labs/rag/comparisons`가 typed import/detail/summary, repository, service, owner API를 소유한다.
- additive migration0067로 `rag_comparison_reports`를 만든다. 원래 DB·계정·기존 행을 보존한다.
- API `/api/v1/admin/rag/comparisons` POST/GET와 `/{id}` GET. 인증·owner 필요, 현재 소유권/원문 접근 재검사, no-store.
- 수입 키+소유자 uniqueness와 canonical digest로 동일 재전송은 기존 기록 반환, 변경 내용은409. 실제 완료시각과 수입시각을 분리한다.
- question, title, model/provider labels, ordered requests, reference evidence와 실제 답변/citations, 자동 관측, 수동 항목별 의미 검토, 텍스트 분석/한계를 저장한다. 모델명과 실제 측정값을 제품 코드에 고정하지 않는다.
- 시간·토큰은 유한한 비음수, 순서/참조는 중복과 미존재 금지. 비용은 Decimal 문자열이며 합계 일관성을 검사한다. 미측정 TTFT와 native 단계, 실제 청구 미확인은null로 남긴다.
- evidence는 현재 DB의 ID·본문·page/bbox/char 범위·projection/chunk 관계와 대조한다. current document/asset/projection/index READY 및 workspace 읽기 검사를 수입·목록·상세에 적용한다.
- 공급자 response_id/원시 응답·계정 잔액·키·임의 파일 경로·원격 URL은 제외한다. 추론 호출·평가 게이트·운영 프로파일 갱신과 연결하지 않는다.

## 화면

- 평가 비교 선택에 ‘저장된 모델 비교’를 추가한다. 선택할 때 별도 목록을 조회해 기존 평가 흐름과 초기 비용을 보존한다.
- 실행 화면에는 같은 목록/상세로 가는 별도 진입점을 둔다. 기존 실행 통계에 합산하지 않는다.
- `/admin/rag/comparisons/[comparisonId]`에서 질문·완료시각·고유질문/요청 수, 전체 시간 비교와 native 분해, 첫/반복 선택, 모델별 실제 답변·인용·품질, 토큰·비용, 상세 분석·한계를 제공한다.
- 인용은 원문 발췌와 기존 정확 위치 원문뷰어 링크를 제공한다. 형식/인용 통과·이전 답변 일치·해당 질문 의미 검토를 별도 표시한다. 전체 모델 품질 통과로 확대하지 않는다.
- 결과 파일 가져오기는 인증된 관리자만 가능하다. JSON 파일을 선택해 제목·모델/요청 수를 확인하고 저장한다. 크기/형식 오류는 파일 본문을 로그에 남기지 않고 표시한다. 수입은 모델 실행이 아니다.
- 공용 Button/ChoiceGroup·의미 토큰·44px 조작·키보드 포커스·320/375px 배치를 사용한다. 오류/권한 철회 때 이전 보고서 본문을 남기지 않고 늦은 응답을 취소한다.

## 실제 자료 연결

동결 결과/ledger/preparation/독립 검토와 공개 fixture에서 허용 필드만 추출한 import artifact를 만든다. 원본 해시는 검증하고 동결 파일은 수정하지 않는다. 관리자 본래 로그인으로 업로드해 저장/새로고침/두 진입점/인용을 확인한다. 공개 데이터라도 관리자 기록을 공개 전시실로 배포하지 않는다.

## 성공 기준

1. 원본4개 시간·답변·인용·토큰과 예상USD0.000667이 그대로 조회된다. TTFT미측정·청구미확인·고유질문1개가 명확하다.
2. 동일 수입은중복0, 변경충돌409, 비로그인401/비owner403/다른소유자404와 원문철회 fail closed를 검증한다.
3. 기존 실행·평가·대화·생성 계약의 관련 회귀, Python/TS 타입·린트·OpenAPI가 통과한다.
4. 본래 환경 DB migration/저장/조회, 실제 브라우저 두 진입점·새로고침/복귀·원문 링크, 모바일/키보드를 검증한다. 합성 화면과 실제 환경의 검증을 구분한다.
5. 기존 데이터/설정/동결 결과를 보존하고 새 모델 호출0. 미완료가 있으면 구체적으로 기록한다.
