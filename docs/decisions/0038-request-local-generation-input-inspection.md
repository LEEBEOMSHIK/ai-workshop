# ADR-0038: 요청 수명 안의 생성 입력 확인

- 날짜: 2026-10-16
- 상태: 사용자 요청 범위에서 구현

## 결정

기존 비공개 검색 진단에 선택적 `generation_input`을 추가한다. 실제 요청을 만드는
local OpenAI-compatible 어댑터에서 최종 messages와 응답 스키마 등 명시된 본문 필드만
포착한다. 주소·인증 헤더·secret과 owner 전용인 Provider 원시 모델 ID는 수집하지 않는다.
사용자용 모델명·버전만 별도 표시하며, JSON과 해시는 전체 HTTP 패킷이 아닌 허용 필드의
정규 직렬화에 해당한다. messages 안의 최종 문자열은 그대로 보존한다. 응답 수신은 어댑터 경계의 관찰이며
모델 내부의 해석·토큰화·잘림이나 정답을 증명하지 않는다. 미지원 provider와 과거 기록의
입력을 현재 설정으로 재구성하여 실제 전송 입력인 것처럼 표시하지 않는다.

진단을 명시 요청한 실행만 수집한다. 입력 확인 본문은 최대 131072 Unicode 문자이며,
초과 시 일부를 자르지 않고 본문 전체를 생략하고 크기·해시·생략 사유만 반환한다.
이 한도는 모델 입력 예산이 아니라 이 진단 계약의 고정 응답 크기 상한이다.
기존 모델 입력, 선택·예산 알고리즘과 전송 동작은 변경하지 않는다.

최종 사용자·원문 권한 재검증을 통과한 응답에만 포함한다. 대화 저장 직전에 이 필드를
제외하고, 현재 요청의 권한 재검증된 비가림 응답에만 다시 결합한다. 재조회·재시도 재생에는
원문 스냅샷이 없으며 입력을 확인하려고 자동으로 모델을 호출하지 않는다.
기존 선택/제외 사유와 원문 뷰어 경계를 재사용하며 새 원문 로그·테이블을 만들지 않는다.

## 검증

공개 합성 표본과 mock을 사용해 최종 지침 추가 이후의 입력 일치, 원문·인용 ID 보존,
진단 비활성·실패·크기 초과·요청 격리, 저장 제외·권한 가림·현재 응답 결합과 UI 빈/오류
상태를 검사한다. 실제 모델·DB·Elasticsearch·서버 기동은 이번 구현 검증에 포함하지 않는다.
