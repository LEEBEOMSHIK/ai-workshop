# ADR-0028: 관리자 문제 이력과 문서 버전의 DB 보존

- 상태: 제안됨 — 상세 설계 사용자 검토 전
- 날짜: 2026-09-27

## 배경

관리자 문제·개선 이력 화면은 저장소 JSON과 Markdown을 직접 읽는다. 사용자는 카테고리 관리와 관련 문서의 DB 연결을 요청했다. 경로 참조만으로는 배포 환경 독립성과 당시 근거의 보존을 충족하지 못한다.

## 제안 결정

Platform Issue History를 두고 기존 PostgreSQL에 카테고리, 문제·누적 사건, 문서와 불변 본문 버전 및 문제-문서 버전 관계를 저장한다. 운영 정본은 DB이며 Git 기록은 최초 이관 입력으로 보존한다. 관리 API와 UI를 통해 이후 기록을 갱신한다.

Assets의 사용자 파일·휴지통과 Learning의 학습 메모 수명주기는 재사용하지 않는다. 인증·SQLAlchemy·오류·감사 기반은 재사용한다. 공개 앱에는 라우터를 등록하지 않는다.

## 영향

문서 체크아웃 없이 근거 조회가 가능하고 이전 버전이 유지된다. 대신 migration, 멱등 이관, 동시 변경 제어 및 관리 API 검증이 필요하다. 새 DB·계정·RAG 색인은 만들지 않는다.

정확한 스키마·권한·이관·복구·검증 계약은 [상세 설계](../superpowers/specs/2026-09-27-issue-history-database-design.md)를 따른다. 이 ADR은 구현 완료를 의미하지 않는다.
