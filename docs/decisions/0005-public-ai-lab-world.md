# ADR-0005: 공개 첫 화면은 DOM·CSS 기반 AI 연구소 월드로 제공한다

- 상태: 일부 대체됨 (`ADR-0006`)
- 결정일: 2026-09-03

## 배경

공개 `/`와 `/labs`는 인증 없이 기술 관리자 캐릭터와 RAG Lab을 소개하지만, 현재 구현은
최대 폭 카드형 랜딩과 Lab 장면으로 나뉘어 있다. 캐릭터 소개도 중앙 모달로 표시돼 방문자가
하나의 연구소 공간에서 일하는 관리자를 발견하고 상세 기능으로 이동한다는 제품 의도가
약하다.

Canvas나 WebGL은 공간 표현에는 유리하지만 접근성, 반응형, 번들 크기와 테스트 비용을 크게
늘린다. 현재 공개된 Lab은 RAG 하나이며 자유 이동 게임 기능은 필요하지 않다.

## 결정

`/`를 공개 AI 연구소 월드의 canonical 입구로 삼고 `/labs`는 리다이렉트하지 않은 채 같은
서버 컴포넌트와 catalog로 동일한 월드를 직접 렌더링한다. 이 중 두 URL의 동일 화면 결정은
사용자 흐름을 재확인한 `ADR-0006`으로 대체한다.

월드는 React DOM과 CSS Grid·장식으로 구현한다. 현재 공개된 RAG 방과 작업 중인 관리자만
표시하고 미래 Lab의 빈 공간을 미리 만들지 않는다. 캐릭터 소개는 기존 modal 접근성 계약과
body portal을 유지하되, 데스크톱에서는 캐릭터 위치에 연결된 말풍선으로, 모바일에서는
safe area를 반영한 하단 대화 패널로 표현한다.

세부 화면·반응형·검증 계약은
`docs/superpowers/specs/2026-09-03-full-screen-ai-lab-world-design.md`를 따른다.

## 결과

### 장점

- AI 연구소라는 프로젝트 정체성과 캐릭터·기술 공간 관계가 첫 화면에서 바로 드러난다.
- DOM 의미 구조, 키보드와 화면 읽기 지원을 현재 React 테스트 체계로 검증할 수 있다.
- `/`와 `/labs`의 중복 구현을 없애고 직접 접근 가능한 두 공개 URL을 보존한다.
- 실제 Lab이 생긴 만큼만 확장해 가짜 기능이나 과도한 추상화를 피한다.

### 비용

- 캐릭터 위치와 viewport에 맞춘 말풍선 flip·clamp 계산이 필요하다.
- 여러 화면 크기, 낮은 높이, 확대와 동작 감소 설정을 실제 브라우저에서 검증해야 한다.
- 두 번째 Lab을 추가할 때 공간 배치와 공통 방 계약을 다시 평가해야 한다.
