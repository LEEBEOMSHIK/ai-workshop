## 실제 신규 실패·재조회

승인된 합성 PDF 한 개만 선택하여 기존 UI에서 실행했다. 새 실행 `eb76c3a1-d71f-46dc-b797-4c23023fb7e9`는 4.60초에 `query_tokenizer_unavailable`로 실패했다. 요청 4.20초·이전 대화 0.06초·검색 실패 0.05초·저장 0.10초, 문맥화·선택·생성·인용은 생략이다. 답변과 인용은 없다. 목록·상세·브라우저 새로고침과 독립 DB 조회에서 같은 오류·단계·시간을 확인했다.

8개 단계가 모두 종료 또는 생략돼 `complete=true`, turn `execution_terminated=true`다. 관측 완료는 답변 성공·품질 합격을 뜻하지 않는다. 생성 모델은 실행하지 않았으므로 외부 모델 실패 E2E로 확대하지 않는다.

기존 `.env`의 `model_cache_root=.local-data/models`는 상대 경로다. 직전 숨김 시작 스크립트가 환경 로딩 후 `backend`로 이동했고 해당 위치의 캐시는 없다. 같은 고정 `intfloat/multilingual-e5-base` revision `d128750597153bb5987e10b1c3493a34e5a4502a`로 네트워크 차단·remote code 금지 probe를 수행했다. 잘못된 경로는 `OSError/LocalEntryNotFoundError`로 실패했고 기존 루트 캐시는 토큰 10·768차원 encode에 7.65초로 성공했다. 다른 모델·캐시·환경으로 전환하거나 다운로드하지 않았다.

독립 본래 DB 읽기에서 진행 중 대화·실행·평가 모두 0건을 확인한 뒤 기존 API만 재시작했다. API PID 58444·숨김 launcher 46916, 동일 포트 18000, 직접 health·ready와 프론트 경유 health 모두 200이다. 프론트·Docker·worker/beat·계정·자료·모델·runner 등록·ES 별칭 gate는 변경하지 않았다. 과거 취소 미종료 turn 한 개를 보존했으며 재시작을 해당 실행의 종료 증거로 사용하지 않는다.

## 검색 복구 뒤 근거 선택

같은 합성 PDF와 같은 대화의 다음 실행 `635092e7-2d71-46ec-b1ac-ac09c2e5e5a3`은 43.716초에 completed/insufficient_evidence로 종료됐다. 검색과 선택·저장은 완료됐고 생성·인용은 미실행, `complete=true`·`execution_terminated=true`를 독립 DB에서 확인했다. 더 직접적인 지급일 표현의 후속 실행 `f2a7e50d-45f1-499c-ac1e-f2a3a3a44741`도 23.463초에 no_eligible_evidence로 안전 종료됐다. retrieval 6,704.59ms·selection 11,764.70ms, 생성·인용·이전 대화 문맥화는 생략됐다. 검색 경로 복구를 확인했으나 답변·멀티턴 문맥 유지 성공으로 확대하지 않는다. 품질 후보 승격이나 임계값 변경은 하지 않았다.
