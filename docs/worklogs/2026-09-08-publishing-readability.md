# 공개 연구 기록 가독성 개선

- 범위: 사용자가 승인한 목록·상세의 기술 아티클 스타일, 관리자 미리보기 일치.
- 변경: Publishing 컴포넌트/스타일/테스트 5개. API·권한·공개 편집본·DB·모델·공통 전역 스타일은 그대로다.
- 작업 방식: 프론트/TDD 구현과 메인 실제 브라우저 검증·독립 코드 리뷰를 분리했다.

## 원인과 개선

목록은 전역 랜딩용 거대 명조체 제목을 상속했고 카드에서 긴 제목이 두 번 표시됐다.
상세는 하나의 긴 문단과 붙어 있는 큰 박스들로 구성됐으며 공개 화면 전용 제목 규칙 때문에
관리자 미리보기와 글자 크기가 달랐다. 상단 공통 메뉴는 부분 CSS 범위 밖이라 기본 파랑이었다.

- Publishing 범위의 명명된 디자인 토큰으로 제목·색상·간격을 통일했다.
- 목록은 주제·한 번만 나오는 제목 링크·요약·읽기 표시와 반응형 3/2/1열 카드로 정리했다.
- 상세 본문만 50rem으로 제한하고 28–40px 고딕 제목·17px 본문·문단 간격·구분선을 적용했다.
- 빈 줄을 문단 경계로 사용하되 문단 내부 LF/CRLF·텍스트 순서·React 이스케이프는 보존했다.
  Markdown/HTML 해석이나 임의 소제목 추론은 하지 않는다.
- StudyBody 자체에 읽기 스타일을 두어 공개 상세와 관리자 미리보기에 동일하게 적용했다.
- Publishing 화면의 상단 메뉴 3개까지 기본/방문/hover/키보드 포커스 스타일을 적용했다.

## 검증

- 변경 전 UI 테스트는 의도한 3건 실패, 수정 후 Publishing 31개(관리자 미리보기 포함) 통과.
- TypeScript와 전체 ESLint 통과. 독립 리뷰는 수정 5개 파일에 중요/차단 문제 없음으로 승인했다.
- 실제 Edge의 1440/960/390에서 변경 전 문제 37건을 재현했다. 수정 후 같은 검사에서
  제목 크기/서체, 메뉴 3개 대비 4.5:1 이상, 카드 제목 중복 없음, 본문 폭·문단 보존,
  공개 문맥 밖 같은 renderer의 제목 일치, 키보드 포커스/목록 복귀, 가로 넘침 없음이 통과했다.
- 카드 링크의 접근성 이름에 읽기 목적이 포함돼 초기 검증 선택자를 정확한 상세 경로로
  보완했다. 제품 오류를 숨긴 것이 아니라 같은 카드의 시각적 제목 중복 검사를 유지했다.
- API 조회를 전후 비교해 기존 공개 snapshot 15건이 바뀌지 않았음을 확인했다.
- 실제 owner 로그인/편집을 자동 수행하지 않았다. 관리자 미리보기는 공용 컴포넌트 테스트와
  브라우저에서 동일 article의 공개 전용 부모 유무에 따른 스타일 비교로 확인했다.
- 최종 production build 통과(종료 0). 기존 publishing-build 인스턴스를 재사용했다.
  Next가 추가한 테스트 인스턴스 타입 경로만 원복하고 TypeScript를 다시 확인했다.

## 최종 인계

실제 로컬 화면에서 확인 가능하다. main의 기존 변경은 보존했고 커밋/푸시는 하지 않았다.
사용자 데이터 변경이나 캐시 삭제는 없다. 기존 캐시 정리 승인 대기는 별도 유지한다.

## 확인 경로

`http://127.0.0.1:5173/labs/rag/studies` → 기록 제목 클릭 → 상세 읽기 → 목록으로 돌아가기.
관리자는 `/admin/publishing`에서 미리보기를 확인할 수 있다. 기존 RAG/모델 동작은 변경하지 않았다.
