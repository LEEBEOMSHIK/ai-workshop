# ADR-0024: 문서 버전과 외부 전송 승인 수명주기를 분리한다

- 상태: 승인됨, 구현 중(2026-09-10)
- 정본: [승인 복구 설계](../superpowers/specs/2026-09-10-document-transfer-reapproval.md)

동일 파일의 재업로드나 내용 변경 없이 승인 취소 후 재승인이 가능해야 한다.
기존 문서 버전/해시는 유지하고, 공급자별 승인 세대와 불변 승인/철회 이벤트를 분리한다.
과거 승인 행을 초기화하지 않으며 기존 철회 주체가 없으면 미기록으로 남긴다.
호출 binding에 승인 세대를 결합해 재승인이 과거 일회 호출을 되살리지 못하게 한다.
기존 binding은 새 세대로 소급 보정하지 않고 거절한다.
권한 없는 사용자의 요청은 자료 검토 요청일 뿐 전송 승인·개인 Codex 실행 권한이 아니다.
이 결정은 기존 owner-only 실행, 공간 접근/외부 정책, 평가/도메인 준비 조건을 완화하지 않는다.
