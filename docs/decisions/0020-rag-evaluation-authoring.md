# ADR 0020: RAG 평가 작성과 기본값 독립 통과 반영

- 상태: 설계 승인 / 구현 중
- 기준일: 2026-09-09
- 상세 계약: [평가 작성 설계](../superpowers/specs/2026-09-09-rag-evaluation-authoring-design.md)

## 맥락

첫 평가 자료와 통과 기준을 관리자 UI에서 만들 수 없고, 기존 통과 상태 반영은 전체 기본값
승격에 묶여 있다. 도메인마다 검증된 구성을 연결하려면 평가 통과와 전체 기본값 선택을 분리해야 한다.

## 결정

owner의 현재 권한으로 본문 없는 문서 목록을 먼저 조회하고, 선택한 정확한 활성 문서 버전의
완전한 근거를 제한된 크기 안에서 제공한다. 정답은 사람이 직접 작성하며 서버가 실제 근거 범위와
지문을 다시 확인하여 기존 불변 데이터셋·실행을 생성한다. 기존 worker와 평가 지표를 재사용한다.

정확한 구성 버전과 명시적 실행의 정책 검증을 통과하면 평가 상태만 PASSED로 반영한다.
이 동작은 다른 구성이나 전체 기본값에 영향을 주지 않는다. 기본값 승격은 별도 명시적 작업으로
남기며 같은 품질 게이트를 사용한다. 기존 API는 호환성을 유지하고 새 migration은 도입하지 않는다.

## 결과

- 첫 안내형 작성은 BM25와 동일 처리·색인의 한 후보만 지원한다. 교차 색인 정답 대응을
  임의로 구현하거나 다른 근거 ID를 합쳐 기존 지표를 왜곡하지 않는다.
- 조회·실행 때 권한을 다시 확인하고 전체 범위를 조용히 자르지 않는다.
- PASS는 검색 평가 증거이며 생성 준비·전송 동의·실제 답변 품질 검증을 대체하지 않는다.
- 새 버전은 PENDING이며 평가 반영과 전체 기본값을 UI에서도 각각 표시한다.
- 별도 영구 승인 이벤트 감사 저장은 제공하지 않는다. 기존 불변 평가 기록과 이번 응답의
  실행·정책 연결을 구분하며 구현 검증 및 실제 활성화 완료를 별도로 보고한다.
