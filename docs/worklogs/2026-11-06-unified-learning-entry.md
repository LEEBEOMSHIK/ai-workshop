# 학습 기록 작성 진입점 통합

## 요구와 범위

사용자 승인에 따라 새 메모·새 실험을 새 기록 하나로 통합한다. 기본은 자유 기록이며 작성기에서 실험 항목 추가를 선택한다. 기록 종류의 저장 계약과 기존 목록 필터는 유지하고 API·DB·모델은 변경하지 않는다.

## 동작과 수용 기준

- 목록의 작성 버튼과 작성기 제목은 새 기록으로 통일한다.
- 실험 항목을 켤 때 제목·본문·참조를 보존하며 별도 전환 확인을 요구하지 않는다.
- 같은 작성 중 항목을 껐다 켜면 실험 입력값을 복원한다. 끈 상태로 저장할 때는 자유 기록과 experiment=null을 보내며 화면에서 이를 안내한다.
- 기존 실험을 편집하면 항목이 켜져 있고, 기존 메모는 꺼져 있다. 저장하지 않은 변경을 버리는 확인과 충돌 복구를 유지한다.
- 기존 공통 체크박스·필드 및 의미 토큰을 재사용한다. 구현 담당과 독립 코드·실제 화면 검증을 분리한다.

## 검증

- 신규 진입점·토글 회귀 2건이 변경 전 실패함을 확인했다. 학습 기능 전체 14개 파일 90건, 추가 미완성 지표 보존을 포함한 신규 3건이 통과했다.
- 메인 독립 재실행에서 작성 통합·카드 이동 2개 파일 6건 통과. 전체 TypeScript, 대상 ESLint와 디자인 시스템 페이지 ESLint 및 diff 공백 검사 통과.
- 독립 코드 검토에서 note 저장 시 experiment=null, 숨긴 실험 항목 disabled, 다시 켠 지표의 유효성 검사와 원문 보존을 확인했다. 프로덕션 빌드는 이번 변경에서 실행하지 않았다.
- 본래 Chrome에서 단일 작성 버튼·기본 항목 꺼짐, 제목·본문·목적·가설·미추가 지표 이름의 껐다 켜기 보존, 숨긴 필드의 키보드 이동 제외를 확인했다. 다크 375/320px와 라이트 320px에서 가로 넘침이 없었다. 합성 입력을 사용했으며 학습 기록 저장은 하지 않았다.
- 검증 초안 닫기 중 Chrome 확인창에서 자동화 응답이 지연됐다. 이 시점 이후 원래 화면 복원과 ISSUE-00051 후속 DB 이력 저장은 확인되지 않아 완료로 보고하지 않는다. 닫기 취소·확정 로직은 자동 회귀로 검증했다.
