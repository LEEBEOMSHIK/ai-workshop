# Codex 참고 문서 구조

- 상태: 승인됨
- 기준일: 2026-08-29

## 목적

루트 `AGENTS.md`를 200줄 이하의 실행 가능한 지침으로 유지하고, 더 긴 배경·예시·절차는 주제별 참고 문서에서 관리한다.

## 배치 규칙

다음 내용을 루트 `AGENTS.md`에 둔다.

- 저장소 전체에 항상 적용되는 규칙
- 금지 사항과 보안 경계
- 작업 전에 확인할 정본 문서 링크
- 완료 전 반드시 수행할 검증 원칙

다음 내용은 참고 문서로 분리한다.

- 긴 배경 설명과 선택 근거
- 명령 예시와 단계별 운영 절차
- 특정 기술 또는 도메인에만 적용되는 규칙
- 반복되는 체크리스트와 문제 해결 방법
- 여러 예외와 사례가 필요한 규칙

## 참고 문서 위치

| 주제 | 정본 위치 |
|---|---|
| 프로젝트 목적 | `docs/vision/project-vision.md` |
| 전체 아키텍처 | `docs/architecture/system-design.md` |
| 저장소와 모듈 경계 | `docs/architecture/repository-structure.md` |
| 공통 개발·보안·테스트 | `docs/guidelines/development-guidelines.md` |
| RAG 설계와 검색 규칙 | `docs/labs/rag/design.md` |
| 기술 결정과 근거 | `docs/decisions/` |
| Codex 전용 상세 절차 | `docs/guidelines/codex/<topic>.md` |

Codex 전용 참고 문서를 추가하면 루트 또는 해당 하위 `AGENTS.md`에 작업 조건과 링크를 한 줄로 추가한다. 모든 참고 문서를 매 작업마다 읽도록 강제하지 않고, 작업 범위와 관련된 문서만 읽게 한다.

## 하위 지침

특정 영역에 공통 규칙과 다른 지침이 실제로 필요할 때만 그 디렉터리에 `AGENTS.md`를 둔다. 임시 예외가 필요하면 `AGENTS.override.md`를 사용하고 예외가 끝나면 제거한다.

하위 지침도 다음 원칙을 지킨다.

- 공백을 포함해 200줄 이하
- 상위 지침을 불필요하게 반복하지 않음
- 적용 범위와 상위 규칙과의 차이를 명시
- 상세 내용은 가까운 `docs` 참고 문서로 연결
- 더 가까운 지침이 상위 지침을 덮어쓴다는 점을 고려

## 변경 점검

`AGENTS.md`를 수정할 때 다음을 확인한다.

1. 전체 줄 수가 200 이하인가?
2. 저장소 전체에 항상 필요한 내용인가?
3. 기존 정본 문서와 중복되거나 충돌하지 않는가?
4. 상세 설명을 참고 문서로 옮길 수 있는가?
5. 링크가 실제 파일을 가리키는가?
6. 새 Codex 세션에서 지침이 읽히는 구조인가?
