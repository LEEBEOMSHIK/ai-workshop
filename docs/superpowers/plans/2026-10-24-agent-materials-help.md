# 단계 자료 확인과 도움말 구현 계획

**Goal:** 현재 단계의 자료 상태를 이해하고 실제 기록된 근거 본문으로 이동하며 세 펼침 항목의 목적을 `?`로 확인한다.

**Spec:** [기존 모달 설계의 후속 범위](../specs/2026-10-24-agent-modal-readability-design.md#후속-자료-확인-경로와-도움말).

**Architecture:** 기존 AgentTracePanel의 선택 상태와 AgentSpanModal/AgentStepOverview 표시 계층만 보강한다. 새 API·DB·의존성은 없다. 이전 변경181파일 기준 해시를 보관한다.

## 역할과 경계

- 메인: 요구·설계, 본래 브라우저 검증, ISSUE-00035와 WORKBOARD/작업 기록 통합.
- 프론트엔드/테스트 담당: AgentStepOverview, AgentSpanModal, AgentTracePanel 및 필요한 좁은 helper와 해당 테스트. Mermaid·저장/권한 계약과 AgentStructuredContent는 변경하지 않는다.
- 독립 리뷰/통합 검증: 사실성, 다른 분기·미수집/숨김 자료 비노출, 자료 이동과 키보드 도움말을 독립 검토한다. 제품 수정은 하지 않는다.
- 제외: AI/DB/배포 역할은 해당 계층 변경이 없으므로 제외한다. 새 생성·임베딩·설치·프로파일/서비스 변경·commit/push는 없다.

## 구현과 검증

- [x] 재현: 개수만 있는 관리자 입력과 실제 본문이 있는 후속 단계, 접근 제한·미연결·동명 단계·사용 가능0/실제0을 포함한 실패 테스트를 먼저 확인한다.
- [x] 관련 단계 표시와 실제 자료 영역으로 이동을 구현한다. 번호/이름/개수는 기록에서 도출하며 숨김 본문은 파싱하지 않는다.
- [x] 세 펼침 제목의 도움말을 독립 버튼으로 구현한다. hover/focus/click, Escape, 44px, 작은 화면 줄바꿈·겹침 방지를 검증한다.
- [x] 관련 Vitest, 전체 `pnpm exec tsc --noEmit --pretty false --incremental false`, 변경 TS/TSX ESLint를 실행하고 독립 검토한다.
- [x] 본래 로그인된 기존 실행에서 관리자→근거 보관 단계 이동/실제 본문, 도움말 클릭·키보드, 320/375/1280px와 포커스 복귀를 확인한다.
- [x] 기준 보존 비교, ISSUE-00035 누적 갱신, WORKBOARD/작업 기록과 캡처로 마감한다.

## 리뷰 중점

- 공통 evidence_refs와 available_evidence_count를 실제 전달 본문·개수로 승격하지 않는다.
- 부모 관계가 없거나 순환하면 관련 단계 연결을 추정하지 않는다. 이름은 연결 근거가 아니다.
- 도움말은 펼침이나 모달을 실수로 토글하지 않으며 좁은 화면에서 잘리지 않는다.
- 표시 제한, 명시적 빈 배열, 미수집·권한 회수 시 본문과 이동 경로의 상태가 정확하다.
- 단계 이동 뒤 열린 자료를 사용자가 바로 확인할 수 있고 닫기 후 해당 흐름도 노드로 복귀한다.

## 후속 구현: 도움말 호버와 흐름 전체 결과

- [x] 기존187파일 해시 보존, 도움말 클릭 후 포인터 이탈과 저장된 전체 결과/시간의 수용 테스트 확인.
- [x] 클릭 고정 제거, 키보드 포커스 유지, 흐름 상단의 상태·품질·전체 시간 표시와 호출부 연결.
- [x] 관련 Vitest·전체 타입·변경 린트·독립 검토 및 본래 저장 실행/반응형 확인.
- [x] ISSUE-00035 이력·문서 연결, WORKBOARD·작업 기록과 기존 변경 보존 검증.

역할은 기존 분리를 유지한다. 메인은 요구·통합, 프론트엔드 담당은 구현/테스트, 독립 담당은 리뷰·통합 검증을 맡는다. AI/DB/배포 변경과 새 생성은 제외한다.
