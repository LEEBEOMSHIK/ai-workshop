# 나머지 업무 화면 실제 점검·수정 계획

**Goal:** 이전에 미확인한 업무 화면을 본래 로그인 환경에서 확인하고 재현된 디자인 시스템 누락·사용성 결함을 수정한다.

**Architecture:** 기존 React/CSS Modules와 의미 토큰을 유지한다. 기존 [승인 방향·설계](../specs/2026-10-26-design-system-adoption-design.md)와 사용자의 이어서 수정 요청을 따른다. 새 UI 프레임워크나 업무 API 변경은 없다.

**Tech Stack:** 설치된 Next.js/React/TypeScript/CSS, Vitest, CUA 실제 브라우저.

## 범위와 보존

- 기존 계정·자료·누적 체크아웃을 사용한다. 별도 DB/계정, 원문 외부 전송, 모델 호출, 설정 승격, 설치, 기존 서비스 재시작, commit/push는 하지 않는다. 공개 화면의 연결 오류는 독립 검토 후 기존 공개 reader만 재기동해 읽기 전용으로 복구했다.
- 기존 답변·검색·근거·인용·대화 백그라운드 처리 로직은 유지한다. 자동 테스트를 실제 모델 품질 통과로 해석하지 않는다.
- 실제 UI에서 안전한 펼치기·선택·탭·이동·작성 닫기를 확인한다. 권한 변경·발행·모델 실행·자료 저장은 검증을 위해 제출하지 않는다. 관리자 문제 이력 기록만 별도로 저장한다.
- 데이터가 없는 상세 화면과 설정 완료로 접근되지 않는 최초 설정은 그 사실을 기록하고 합성 컴포넌트 검증과 구분한다.
