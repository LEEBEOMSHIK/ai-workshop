# 승인 타임라인 시안 적용

## 표시 계약

사용자가 제시한 원형 번호 타임라인 시안을 승인했다. 이전 순번/학습 기록 열 제목과 행 구분선 방식은 이번 시안으로 대체한다.

- 왼쪽 작은 원 안에 목록 순번1, 2, 3을 표시한다. 앞자리0은 쓰지 않는다.
- 원과 자기 카드 사이 가로선은 해당 순번의 기록이라는 의미다.
- 세로 방향의 선은 저장된 실제 계승 관계가 확인된 경우만 연결한다. 별도 학습·계획·미확인을 임의 연결하지 않는다.
- 카드의 저장된 학습 차수와 상태, 계승 관계, 학습 제목/목표, 확인 결과와 남은 문제를 위계 있게 표시한다.
- 제목·성과를 새로 생성하거나 데이터 내용을 바꾸지 않는다. 전체 카드 링크와 상세 화면은 유지한다.

## 검증 계획

기존 연결 판정·순번 페이지 이동과 카드 접근성을 유지한다. 비인접 대상 사이의 선이 중간 노드에 닿지 않게 한다. 두 테마·320px 실제 화면에서 번호보다 내용이 우선 보이고 겹침·넘침이 없는지 독립 검증한다. 저장 자료와 다른 세션의4차 학습 상세 정리에는 쓰지 않는다.

## 구현 및 자동 검증

원형 순번은 desktop44px/mobile36px이며 원마다 해당 카드로 향하는 가로선을 둔다. 인접 계승은 두 원 사이의 방향선, 비인접 계승은 중간 원 바깥으로 우회한 선을 사용한다. 실제 제목에 옅은 표면을 적용하고 저장된 목표·확인 결과·남은 문제·출발점 원문을 유지한다. 표 제목과 전체 행 구분선은 제거했다.

관련4파일27건 및 인접 방향2건을 포함한 출발점 UI7건 통과, 메인 목록/상세28건 통과. 전체 TypeScript·변경 코드 ESLint·공백 검사 통과.

## 독립 실제 화면 검증

두 테마 desktop/320px에서 원44/36px의 강조가 제목보다 절제되고 표 헤더가 제거된 것을 확인했다. 자기 카드 가로선5개, 명시 계승 세로선3개이며 계획 기록은 가로선만 표시한다. 방향선은 원 경계에서 끝나 숫자를 관통하지 않고 모바일 가로 넘침이 없다. 비인접 우회는 합성 테스트와 독립 코드 검토 범위이며 실제 자료는 연속 계승이다. 다크·기본 폭·목록으로 복원하고 데이터는 수정하지 않았다.
