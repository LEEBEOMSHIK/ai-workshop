# 독립 파일함 1차 구현

## 완료 범위

- `/workshop/workspaces`를 RAG 대화와 구분되는 파일함으로 정리했다.
- 허용된 공간만 회사(company/team)·개인·임시로 구분하고 공간 이름 검색과 빈 상태를 제공한다.
- 기존 문서 탐색기·폴더·업로드·원문·버전 동작을 유지했다. 파일함 복귀 링크, 일관된 전체 폭과 문서 행 메타데이터 배치를 적용했다.
- 작업소 메뉴와 RAG 도메인 선택 화면의 진입 링크를 파일함으로 통일했다.
- 구현은 프론트 담당, 검토는 독립 역할, 통합과 실제 화면 확인은 메인이 수행했다.

## 검증

- UI TDD: 최초 예상 실패4건 확인 → 34건 통과.
- 메뉴/도메인 TDD: 예상 실패7건 확인 → 31건 통과.
- 독립 재검증: 위 5파일 65건 통과(32.99초), 차단 지적 없음.
- 프론트 전체 타입 검사 및 린트 exit 0.
- 실제 로그인 세션: 회사2·개인1의 허용 공간 표시, 개인 필터와 자산운용 공간 이름 검색 확인.
- 기존 합성 참조 공간에서 문서 열기 → Markdown 원문, 버전1·활성 원본, 크기/형식 표시 확인.
- 데스크톱 파일함과 문서 뷰어 배치를 시각 확인했다. 이번 변경의 모바일 실화면 검증은 수행하지 않았다.
- 실사용 데이터 생성·수정·삭제, 업로드, 계정 변경, 서비스 재시작, DB/API 변경 없음. 커밋/push 없음.

## 다음 경계

공간 이름 검색은 문서 본문 검색이 아니다. 선택 문서만으로 대화하는 기능은 현재 API에 문서 범위가 없어 아직 제공하지 않는다.
다음 단계에서 문서 선택·대화 검색 범위의 서버 권한 계약부터 설계한다. 대화 내 업로드, 대화 저장 목록,
문서/폴더 이동·삭제·권한 편집은 별도 구현 범위다. 이번 결과는 Alli 전체 기능 구현이나 실제 LLM 답변 검증을 뜻하지 않는다.
