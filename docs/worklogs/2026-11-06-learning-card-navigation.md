# 학습 기록 카드 전체 이동

## 요구와 구현

- 제목만 연결되던 목록을 카드 전체가 상세로 이동하는 하나의 Next Link로 변경했다. 차수 표식과 연결선은 카드 바깥 장식으로 유지한다.
- 카드 내부에 다른 조작을 중첩하지 않고, 링크의 접근 가능한 이름은 제목으로 제한한다. Tab·Enter, 새 탭 열기와 브라우저 기본 링크 동작을 유지한다.
- 공통 의미 토큰으로 카드 전체 hover 표면·테두리와 focus-visible 윤곽을 표시한다. 데이터·정렬·페이지 크기·저장 계약은 바꾸지 않는다.
- 새 메모는 자유 기록, 새 실험은 목적·가설·절차·결과를 나누는 구조화 기록이라는 설명을 버튼 가까이에 추가하고 aria-describedby로 연결했다. 어느 쪽도 모델 학습 실행 버튼이 아니다.
- 요구 정리·프론트엔드·테스트 설계는 메인, 독립 통합 검증은 별도 담당으로 분리했다. API·DB·모델 변경이 없어 해당 역할은 제외했다.

## 검증

- 신규 회귀 3건은 변경 전 제목 바깥 분류·수정일이 링크에 포함되지 않아 실패했고, 변경 후 통과했다. 자유 메모·완료 실험·계획 각각 비제목 클릭, 한 개의 제목 기반 링크, Tab·Enter, 중첩 조작 부재를 검사한다.
- 목록·순서·계승·디자인 시스템 포함 5개 파일 35개 테스트 통과. 전체 TypeScript와 대상 ESLint, diff 공백 검사 통과.
- Windows 제한 실행의 임시파일 EPERM은 테스트 수집 전 환경 오류로 구분했고, 승인된 실행에서 실제 실패와 통과를 확인했다.
- 독립 회귀 4개 파일 31개 테스트 통과. 본래 로그인한 Chrome에서 제목이 아닌 ‘개선 목표’ 본문 클릭 및 카드 Tab·Enter로 정확한 상세 이동을 확인했다. 중첩 조작은 없다.
- 라이트·다크에서 카드 hover 배경·경계 변화와 키보드 윤곽을 확인했다. 375/320px에서 긴 제목·본문의 가로 넘침이 없고, 새 메모·새 실험의 실제 항목 차이를 저장 없이 확인했다. 작성기를 닫고 기존 다크 모드·기본 폭을 복원했다.
- 이번 변경의 프로덕션 빌드는 미실행이다.
- ISSUE-00051에 2026-11-06 진행 이력을 저장하고 새로고침 재조회했다. 학습 기록 저장·모델 호출은 하지 않았다.
