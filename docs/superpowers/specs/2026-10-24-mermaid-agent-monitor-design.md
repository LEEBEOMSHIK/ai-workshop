# Mermaid 에이전트 흐름도와 단계 상세 모달

사용자 요청(2026-10-24): Mermaid로 전환하고 연결된 노드를 자유롭게 옮기며, 클릭하면 에이전트의 지침·입력·결과를 정리한 모달을 연다. 이 구체적 화면 변경을 이번 구현 범위로 삼는다. 아래 세부 조작은 구현 담당의 선택이며 별도 사용자 결정으로 표현하지 않는다.

## 접근과 범위

- 사용자가 선택한 Mermaid를 실제 렌더러로 사용한다. 기존 React 그림 유지, Mermaid 문법만 만들고 다른 렌더러 사용, 별도 그래프 편집기 도입은 요청과 맞지 않거나 불필요한 의존성을 늘리므로 채택하지 않는다.
- Mermaid의 로컬 패키지로 초기 SVG를 만들고 화면 코드가 노드 이동·연결선 좌표·확대/축소·선택을 처리한다. 외부 렌더링 서비스로 실행 데이터나 지침을 보내지 않는다.
- 현재 모든 span(agent/model/delegation/tool)을 노드로 표시한다. 저장된 parent ID 관계만 연결하고 순서 번호를 인과 관계로 바꾸지 않는다. 중간 단계를 숨기거나 이름으로 ID를 대체하지 않는다.
- 노드 위치는 현재 실행을 보는 동안만 화면 메모리에 유지한다. 모달을 열고 닫아도 유지하고 실행이 바뀌면 초기화한다. DB·localStorage에 본문 또는 위치를 추가 저장하지 않는다.
- 연결 변경·삭제, 모델 실행, 프로파일/호출 예산, 멀티턴 수집 계약, 일반 대화 활성화는 이번 구현 범위가 아니다.

## 흐름도 조작

- 노드를 드래그하면 해당 노드에 연결된 선의 시작·끝점이 함께 이동한다. 연결은 고정이다.
- 클릭과 드래그를 구분해 이동을 마칠 때 상세 모달이 열리지 않는다. pointer cancel과 실행 변경 뒤 오래된 이벤트를 처리하지 않는다.
- 빈 배경 이동, 확대/축소, 화면 맞춤, 원래 배치 복원을 제공한다. 화면에 맞추는 것과 위치를 초기화하는 동작은 구분한다.
- Tab으로 노드에 접근하고 Enter/Space로 모달을 연다. 방향키로 노드를 이동할 수 있으며 사용법을 짧게 안내한다. 키보드·터치와 320/375px 폭에서도 같은 데이터를 확인할 수 있다.
- 로딩·렌더링 실패·관측 누락·빈 기록은 구분한다. Mermaid 실패를 정상 그래프로 가장하지 않고 전체 단계 목록을 통한 상세 조회를 유지한다.
- Mermaid strict 모드와 HTML label 비활성화를 유지한다. 생성 문법의 ID는 내부 순번으로 만들고 이름의 문법 구분 문자만 표시용 전각으로 치환한다. 정확한 저장 이름은 모달/접근성 이름에 유지한다. 통제된 줄바꿈 외 데이터에서 Mermaid 지시문·스크립트·클릭 콜백을 실행하지 않는다.

## 상세 모달

- 클릭한 정확한 span ID의 이름·종류·상태·시간·역할/위임 관계를 표시한다. 동일 이름의 다른 실행을 혼합하지 않는다.
- 지침, 전달 입력, 반환 결과를 명확한 구역으로 구분한다. 알려진 JSON은 질문·재작성 질의·이전 메시지·근거·메시지 역할·답변 주장 등 실제 필드로 정리한다. LLM 요약 호출이나 기록에 없는 설명을 생성하지 않는다.
- 원문은 별도 펼치기로 그대로 확인할 수 있다. 문자열·빈 문자열·알 수 없는 JSON·긴 본문을 안전하게 처리한다. 원문 길이·SHA는 보조 기록에 둔다.
- retained/current 조건과 기존 미보관·미수집·해당 없음·검증 실패 숨김·크기 초과 상태를 유지한다. 숨겨야 할 원문은 모달 DOM에도 넣지 않는다.
- 반환값은 관측된 단계 출력임을 표시한다. 최종 검증 답변이나 모델의 비공개 추론으로 표현하지 않는다.
- 현재 권한으로 제공된 원문 링크를 유지한다. 모달은 Escape·닫기 버튼·배경 클릭으로 닫히며 포커스를 호출 노드로 돌려준다. 포커스는 모달 안에 머물고 배경 스크롤을 잠근다.
- 데스크톱은 지침/입력과 결과를 가까이 비교할 수 있고 모바일은 세로로 읽는다. 길어진 본문은 모달 안에서 스크롤한다.

## 수용 기준

1. 실제 Mermaid SVG가 기존 로그인된 완료 실행에서 표시된다.
2. 기존5단계를 모두 선택할 수 있고 실제 부모 관계를 유지한다.
3. 노드 이동 후 연결선 끝점이 새 위치를 따라가며 클릭/드래그가 분리된다.
4. 각 노드의 지침·입력·결과가 모달에서 해당 기록과 일치한다. 과거 영어 원문을 임의 번역하지 않는다.
5. 미보관·검증 실패 등 정책과 동일 이름/다른 ID·실행 전환·렌더 지연/실패를 회귀 검증한다.
6. 관련 테스트·타입·린트, 실제 CSS의320/375/1280px와 키보드, 본래 환경 제공 화면을 확인한다. 합성 검증과 실제 모델 결과를 구분한다.
