# 학습 목록 화면의 강조 순서 정리

## 승인된 구성

- 큰 소개 박스를 없애고 제목·짧은 소개와 오른쪽의 주요 ‘＋ 새 기록’ 버튼으로 구성한다.
- 작성 방법·저장 관련 안내는 작성기를 열었을 때 표시한다.
- 중복 ‘내 기록’ 제목을 없애고 목록 위에는 간결한 정렬·상세 필터만 유지한다.
- 페이지당 표시 개수는 목록 하단 페이지 이동 옆으로 옮긴다.
- 기존 필터 상태·초기화·작성·카드 링크·접근성·두 테마를 유지한다.

## 범위와 검증

프론트엔드 배치 변경이며 구현, 독립 코드 검토 및 본래 화면 검증을 분리했다. API·저장 데이터·다른 세션 학습 작업은 변경하지 않았다. ISSUE-00051 DB 이력 쓰기는 앞선 자동 승인 거절 범위이므로 재시도하지 않는다.

- 신규 배치 회귀의 변경 전 실패를 확인한 뒤 관련 4개 파일 18건 통과.
- 메인 독립 회귀에서 필터·작성·카드 이동·디자인 시스템 4개 파일 13건 통과.
- 전체 TypeScript, 대상 ESLint와 디자인 시스템 페이지 ESLint, diff 공백 검사 통과.
- 주요 버튼이 기존 hero/panel 버튼 스타일 범위 밖에서 공통 primary variant를 사용하며 목록 영역의 접근 가능한 이름과 기존 저장/조회 상태를 유지함을 독립 검토했다. 이번 변경의 프로덕션 빌드는 미실행이다.
- 본래 Chrome의 다크·라이트 데스크톱과 320px에서 배치를 육안 확인했다. 제목 오른쪽 주요 버튼, 첫 카드 노출, 작은 정렬·필터, 하단 표시 개수와 페이지 이동을 확인했고 가로 넘침이 없었다.
- Enter로 빈 작성기 열기·닫기, 표시 개수 10개 변경 중 주제 조건 유지 확인. 입력·저장 없이 다크·기본 폭·최신순·5개·조건 초기화·상세 접힘·작성기 닫힘으로 복원했다. 문제 이력 저장 재시도는 하지 않았다.
