동의 문장 전체를 테두리 있는 클릭 영역으로 만들고 네이티브 체크박스·키보드 초점을 유지했다.
비활성 이유, 실행/조회 버튼 간격과 관리자 색상을 적용했다. 요청 중 이전 성공 문구는 숨긴다.
명시적 동의·구성 버전·요청 중 차단·요청 후 동의 초기화는 유지한다.

## 후속: 검사 결과 유지와 재검사 분리

사용자가 실행한 뒤 화면에는 request_failed가 남았으나 수동 저장 상태 조회는 통과였다.
체크박스 초기화만으로 결과를 해석할 수 없으며 전송 응답 실패가 서버 검사 실패를 뜻하지는 않는다.

- 성공 결과와 checked_at을 보존하고 성공 상태에서는 동의 영역 대신 ‘다시 검사’를 표시한다.
- 재검사를 선택하면 새 동의가 필요하다. 단순 GET 조회는 동의를 소비하지 않는다.
- 실행과 조회의 진행 안내를 구분한다. 최신 요청 실패 시 이전 결과·시각을 이전 기록으로 명시한다.
- POST 통신/응답 불명 오류는 결과 미확정과 저장 상태 조회를 안내한다. 자동 재실행하지 않는다.
- 새 페이지에서는 기존 수동 조회로 저장 결과를 불러온다. 브라우저 저장소나 자동 요청은 추가하지 않았다.
