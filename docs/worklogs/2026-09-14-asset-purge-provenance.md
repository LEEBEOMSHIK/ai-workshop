## 범위와 실행 경계

출처 관계, 버전된 삭제 대상 목록, 실행에 결합된 검증 결과, 본문 없는 최소 증명 저장 기반을 구현한다.
실제 삭제 명령·worker·UI는 연결하지 않는다. 순수 판정의 boolean은 서버 증거 인증이나 권한 검사를 대체하지 않는다.
실사용 DB에는 이번 migration을 적용하지 않았으며 서버 재시작·사용자 자료 삭제·push도 하지 않는다.
기존 main의 UI 변경과 사용자 자료는 보존한다. 새 패키지·가상환경·worktree를 만들지 않는다.

## 전체 회귀에서 발견한 문제

첫 전체 실행은 467 passed, 3 failed, 기존 경고1건이었다.
실패는 모두 `test_trash_migration.py`가 최신 migration 기대값을 `0037`로 고정해 둔 검사였다.
실제 격리 DB에는 `0039`가 적용됐고 downgrade 거부 뒤에도 동일 버전을 보존했다.
최신 버전 기대값을 Alembic 설정에서 독립적으로 읽도록 보완하며, 기존 자료 보존·실패 rollback 검사는 유지한다.
수정 후 관련 전체 회귀475건을 재실행해 통과했다.

추가로 독립 리뷰에서 배치 유입/기존 버전 삭제 경합과 ORM identity map의 오래된 header/participant 값을 사용하는 가능성을 확인했다.
job→batch→문서/폴더→버전 잠금과 최신 값 재조회로 보완하고, 실제 PostgreSQL 5개 실패 사례가 수정 후 통과하는 것을 확인했다.

## 검토로 보완한 계약

증명 결합 함수에도 신뢰된 필수 참여자 집합을 명시적으로 공급하도록 강화했다.
응답에 포함된 참여자만으로 완전성을 판정하면 누락을 놓칠 수 있기 때문이다.
누락·추가·빈 집합 거부 회귀를 추가했으며, 내부 호출자는 새 필수 인자를 전달해야 한다.
이 계약 변경은 아직 공개 API나 실제 삭제 경로에 연결되지 않았다.

또한 상세 자원 목록을 지운 뒤에도 증명 결합값을 검증할 수 있도록, 최소 증명에 목록 결합값을 보존하고 최종 결합 대상은 남기는 식별자·세대·계약·검증 결과로 제한한다.
아직 배포되지 않은 내부 결합 형식의 변경이며 후속 검증기는 같은 canonical 형식을 사용해야 한다.

SQL 매핑은 내부 `purge_inventory_storage.py`로 분리했다. 공개 계약은 유지하며 내부 파일과 import 하나를 추가로 관리하는 비용이 있다.

최종 검토에서 최소 증명 재구성 테스트가 초기 입력값을 재사용하는 빈틈을 보완했다.
저장된 대상 행만으로 식별자·세대를 재구성하며, 의도적으로 잘못된 매핑을 넣었을 때 실패하는 것을 확인했다.
검사 후 제품 코드는 원상 복구됐음을 비교했고, 메인 집중91건과 독립 재검토를 통과했다.

## 남은 활성화 조건

각 모듈의 실제 출처 등록/목록 수집, 기존 자료의 출처 확인, 검색·조회·worker 차단, 실제 정리와 잔존 확인, 제한된 완료 명령을 연결해야 한다.
백업 복구 안전성은 rollback 경계 밖 권위 원장과 복원 후 공개 차단 게이트가 추가로 필요하다.
본 단계만으로 파일함 영구 삭제를 사용자 테스트 가능한 기능이라고 보고하지 않는다.

## 검증 구분

| 확인 대상 | 현재 경계 |
|---|---|
| 다른 job·목록·세대·자원 revision 검증 결과 거부 | 순수 계약 단위 검증 완료 |
| 필수 참여자 누락·불완전 조회·공유 대상 잔존 | 순수 계약 단위 검증 완료 |
| 실제 원본/공간/버전 조합과 SQL 제약 | 격리 DB 검증 및 독립 검토 완료 |
| 최소 증명과 상세 정리의 트랜잭션 | 합성 자료 격리 DB에서 commit·rollback·증명 생존 검증 완료 |
| 실제 원본/파생물 삭제와 백업 복구 | 이번 범위 제외, 미검증 |

## 인계

- main의 변경 파일로 유지하며 이번 작업에서 커밋·푸시는 하지 않았다. 기존 UI 변경을 보존했다.
- 실사용 DB migration·서버 재시작·사용자 자료 삭제·삭제 API/worker 활성화는 하지 않았다.
- 검증 전용 UUID DB는 helper의 소유 대상 정리 절차로 제거했다.
- 다음 작업은 각 모듈의 실제 출처 등록 및 삭제 대상 목록 수집 어댑터 연결이다.
- 임시 에이전트 검토 기록은 CACHE_POLICY의 정확한 대상 보고·승인 후 정리 대상이다.
