# RAG 비교 실험 사용성 개선 — 2026-09-28

## 문제와 변경

평가 사례 콤보박스는 질문 전체와 실패 위치를 숨겼고, 반복 시도 카드를 모두 나열해 구성 간 답변 비교가 어려웠다. 검색 근거 충족률과 유사도의 의미도 화면에서 쉽게 구분하기 어려웠다.

- 평가 사례 선택을 검색 가능한 질문 목록으로 바꾸고 전체·실패·근거 부족·검토 필요·진행 중 필터를 추가했다.
- 선택 질문의 같은 반복에 대한 최신 답변을 구성 이름과 버전별로 나란히 보여 준다. 이전 재시도 이력은 접어서 보존한다.
- 각 답변의 `유사도·근거 선택 보기`에서 기록된 semantic cosine, keyword coverage, Dense/BM25/RRF 점수와 순위, 선택 임계값·제외 사유·원문 링크를 확인한다.
- 유사도, 정답 근거 충족률, 정답 판정을 구분한다. 미기록 값은 0으로 바꾸지 않는다. 진단 조회는 펼칠 때만 수행하며 모델을 재실행하지 않는다.
- 실행 이력은 펼치는 목록으로 바꾸고 새 평가 준비 영역을 접었다. 비교 탭의 제목·여백·버튼을 정리하고 실제 대화 실행 이력 링크를 제공했다.
- 모바일은 질문 목록과 상세 사이를 이동한다. 질문 선택 및 실행 링크를 유지한다.

## 범위와 남은 작업

이번 변경은 비교 화면의 탐색과 진단 표시다. 검색·생성·권한·DB 계약이나 활성 구성은 바꾸지 않았다. 별도 환경·계정·DB는 만들지 않았다.

기존 전체 평가 `1981b09d-d41c-48f0-a4ee-ed03bf710f1a`는 계속 실행 중이다. 화면 최종 확인 시 전체 150회 중 완료 112, 실패 5, 진행 1, 대기 32였다. 이는 중간 시점이며 최종 품질 결과가 아니다. 전체 정답·인용·지연 판정 및 실패 원인 개선은 계속 필요하다. ISSUE-00005를 품질 해결로 종결하지 않는다.

## 사용자 재검토: 중첩 스크롤과 페이지 길이

최초 개선은 질문을 목록으로 드러냈지만 내부 스크롤과 긴 답변·지표·진단 누적으로 탐색 비용을 충분히 줄이지 못했다. 가로 넘침과 기능 동작만으로 사용성 개선 완료를 판단한 기준이 부족했다.

- 질문 목록의 sticky·85vh·내부 overflow를 제거하고 5개씩 페이지로 이동한다. 선택 질문이 속한 페이지를 유지한다.
- 답변 비교 / 근거·진단 / 검토를 전환하여 필요한 내용만 표시한다. 긴 답변은 6줄 미리보기와 명시적 전체 보기를 제공한다.
- 준비·실행 이력을 같은 줄로 배치하고 상단 중복 설명·제목·여백과 질문 목록의 카드 높이를 줄였다.
- 첫 재수정 실측(1440×741): 질문 목록 내부 스크롤은 없어졌으나 페이지 1998px, 비교 시작 y864px로 여전히 길었다. 이를 보고 상단과 목록을 추가 압축했다. 이 수치는 최종 수정 후 수치가 아니다.
- 최종 화면 검증은 브라우저 연결 복구 후 이어 확인한다. 최종 레이아웃까지 검증 완료로 보고하지 않는다.

- 재수정 자동 검증: Panel/Results 24개 + Studio 24개 통과, 전체 TypeScript 및 변경 TSX ESLint 통과. 독립 리뷰에서 지적한 탭 방향키·Home/End·roving focus 누락을 회귀 테스트와 함께 수정했다. 기존 자료 불러오기 테스트의 5초 timeout이 1회 발생했으며 재실행24개는 모두 통과했다.
