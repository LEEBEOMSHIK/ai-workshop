# 단계 자료 확인 경로와 도움말

- 날짜: 2026-10-24
- 문제: ISSUE-00035
- 범위: [기존 모달 설계 후속](../superpowers/specs/2026-10-24-agent-modal-readability-design.md#후속-자료-확인-경로와-도움말), [수행 계획](../superpowers/plans/2026-10-24-agent-materials-help.md)
- 상태: 구현·독립 검토·본래 화면 검증 완료

## 사용자 보고와 원인

사용자는 함께 전달된 자료를 확인할 수 없고 아래 펼침 영역이 무슨 내용을 제공하는지 모르겠다고 보고했다. `?` 아이콘을 통한 설명을 요청했다.

본래 로그인된 기존 완료 실행에서 관리자 자료 영역은 사용 가능 근거28개·대화 이력0개를 표시했다. 관리자 입력을 만드는 코드도 question/resolved_query/history/available_evidence_count만 전달한다. 답변 담당 단계에는 실제 입력 근거28개와 본문이 있으며 기존 화면에서 펼쳐 확인했다. 현재 자료 영역이 현재 span 입력만 보여주고 실제 본문이 있는 단계로 이동하는 경로를 제공하지 않아 혼동을 만들었다. 이 사례를 본문 미저장으로 판정하지 않는다.

## 구현 경계

현재 단계의 상태 설명과 실제 부모·자식 경로로 연결된 근거 보관 단계의 이동 버튼을 제공한다. 후보는 열람이 허용된 complete 입력과 실제 근거 text가 있는 경우만 인정한다. 개수·공통 권한 manifest만으로 본문이 있다고 추정하지 않으며 다른 분기·동명·순환·고아 관계도 추측하지 않는다.

적용 지침, 함께 전달된 자료, 원문·기술 기록의 목적은 `?` 도움말로 제공한다. hover/focus/click을 지원하고 도움말과 본문 펼침 동작은 독립적이다. 도움말을 먼저 닫는 Escape와 새로 선택한 단계로 돌아가는 포커스를 검증한다.

기존181개 변경 파일의 해시를 `.local-data/project-agent-work/modal-materials-help-20261024/baseline-sha256.json`에 보관했다. 독립 코드 리뷰·통합 검증은 구현 담당과 분리한다. 신규 모델/임베딩, 설치, 프로파일·서비스·RAG 저장 계약 변경, commit/push는 수행하지 않는다.

## 검증 기록

신규 수용7개 중 새 기능6개가 변경 전 실패하고 기존 빈 배열1개는 통과했다. 구현 후 모달 영향17개를 통과했다. 독립 검토는 Panel→Modal 경계에서 비정렬/동명, 자료 이동/포커스 복귀, 형제·누락·순환 배제, 숨김 getter 미열람과 실행/권한 변경을 확인했다. 독립8개를 포함한 실행 모니터링·대화 진단15파일 **142개 통과**, 전체 TypeScript 및 변경 TS/TSX8파일 ESLint exit0이다. 자체17개와 독립8개는142개에 포함되므로 합산하지 않는다.

독립 검토와 실제 화면에서 graph/modal의 run-only React key 충돌을 발견했다. 독립 회귀1실패를 확인하고 모달 key에 namespace를 구분한 뒤 최종142개와 키 경고 부재를 확인했다. 구현 중 태그 편집의 일시 컴파일 오류도 최종 타입 검사·새 화면 로딩에서 해소됐음을 확인했다.

- `pnpm exec vitest run src/features/rag/executions src/features/rag/conversation/SearchDiagnostics.test.tsx --reporter=dot`: 142개 통과.
- `pnpm exec tsc --noEmit --pretty false --incremental false`: exit0.
- 변경 TS/TSX8파일 `pnpm exec eslint ... --max-warnings 0`: exit0.

본래 로그인된5173의 기존 완료 실행에서 manager 자료의 실제 버튼을 눌러 답변 담당#4와 답변 모델#5로 각각 이동했다. 대상 자료가 자동으로 열리며 실제 입력 근거28개와 지급 규칙 본문이 보였다. #4로 이동 후 닫으면 해당 흐름도 노드에 포커스가 복귀했다. 새 생성·임베딩은 수행하지 않았다.

세 도움말의 클릭/키보드 열기·설명과 Escape 우선 닫힘을 확인했다. hover 및 포인터가 설명으로 이동할 때 유지되는 동작은 단위 테스트로 검증했고 실제 네이티브 hover·터치 장치 검증은 수행하지 않았다.

- CSS1280×900: 모달1216px·가로 넘침0, tooltip360×123px·화면 안.
- CSS320×800: 모달304px·가로 넘침0, tooltip280×123px·화면 안.
- CSS약375×800: 모달358.67px·가로 넘침0, tooltip334.67×123px·화면 안.
- 도움말 버튼은 각44×44px다. 기존 브라우저 배율을 보존하고 임시 viewport override를 해제했다.
- 최종 검증 탭의 오류/경고 로그는0이었다. 기존 탭 연결이 끊겨 같은 브라우저의 새 검증 탭으로 이어갔으며 캡처 시간 초과는 재조회로 복구했다. 제품 장애로 단정하지 않았다.

캡처·좌표는 Git 제외된 `.local-data/browser-verification/modal-materials-help-20261024/`에, 테스트·독립 검토·보존 결과는 `.local-data/project-agent-work/modal-materials-help-20261024/`에 보관한다. 최종 보존 비교는181파일 중174동일·허용7변경·누락0·예상 밖 변경0이다. 미해결 제품 결함은 없다. 기존 RAG 품질 실패와 멀티턴 후속 범위는 그대로 유지한다.

## 문제 이력 연결

인증된 관리 UI에서 ISSUE-00035의 증상·원인·수정·검증에 이번 후속을 누적했다. 이 문서를 `단계 자료 확인 경로·도움말 검증 (2026-10-24)`으로 등록해 문서 `1c58036e-6e4c-4314-bef1-59302afeb90a` 버전1을 연결하고 정확한 연결 URL을 확인했다. 착수와 완료의 진행 이력 저장 완료도 확인했다. 이전 기록과 별도 후속 범위를 보존해 전체 이슈는 진행 중을 유지한다.
