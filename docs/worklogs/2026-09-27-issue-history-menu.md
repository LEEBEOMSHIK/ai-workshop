# 관리자 문제·개선 이력 메뉴

## 범위

- `/admin/system/issues`와 관리자 내비게이션을 추가했다.
- 기존 `docs/issues/issues.json`의 8개 문제를 검색·상태·영역별로 조회한다.
- 같은 문제의 증상, 원인, 수정 방향, 검증 기록, 남은 작업, 날짜별 후속 이력과 문서·커밋을 묶었다.
- 수정은 저장소 이력 파일에서 관리하고 메뉴는 읽기 전용이다. 첫 질문 전 세션 생성 변경은 RAG-0001의 미해결 작업으로 유지한다.
- 기존 체크아웃·계정·서버를 사용했다. 별도 환경·DB·계정·업로드 자료를 만들지 않았다.

## 권한과 실행 조건

마스터 권한 확인 후 서버 파일을 읽고 public 런타임은 차단한다. 문서는 해당 문제의 evidence 인덱스로만 선택하며 `docs/` Markdown과 `WORKBOARD.md`만 허용한다. 경로 이탈·심볼릭 링크와 512KiB 초과 파일을 거부한다. 본문은 HTML 실행 없이 텍스트로 표시한다.

Next 서버는 기존처럼 `frontend/`에서 실행하며 상위 저장소 문서를 함께 보존해야 한다. 내부 파일을 public 디렉터리로 복사하지 않는다.

## 검증

- 관련 UI·내비게이션·권한 테스트 35건과 파일 로더 테스트 6건 통과. 파일 로더 테스트의 Node 기본 export mock 오류를 수정하고 재실행했다.
- TypeScript 타입 검사와 변경 영역 ESLint 통과. 권한 순서 테스트의 mock 타입 보정 후 해당 2건을 재확인했다.
- 본래 프론트5173의 마스터 브라우저에서 메뉴·8개 문제 표시, 상태 필터3개, ID 검색1개, 관련 문서 조회와 목록 복귀를 확인했다.
- 데스크톱 화면 배치를 확인했다. 모바일 실제 화면 검증은 이번 범위에 포함하지 않았다.
- 독립 코드 리뷰에서 차단 문제는 없었으며 문서 화면 여백, 실행 파일 배치 설명, 크기 제한 테스트를 보완했다.

문제 자체의 RAG 답변 품질·실제 첨부 검증 완료를 의미하지 않는다. 각 문제의 남은 작업은 기존 이력에 유지한다.
