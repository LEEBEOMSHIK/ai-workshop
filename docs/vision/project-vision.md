# 프로젝트 비전

- 상태: 승인됨
- 기준일: 2026-08-29

## 정체성

AI Workshop은 AI 기능을 전시하는 포트폴리오에 그치지 않는다. 공부, 실험, 실패, 설계 변경, 최종 기술을 하나의 흐름으로 연결하는 개인 AI 작업소다.

사용자는 내부 작업대에서 정리되지 않은 생각까지 자유롭게 남기고, 실험을 재현 가능한 형태로 발전시킨다. 외부 방문자는 그중 승인된 결과와 선별된 시행착오를 캐릭터형 에이전트의 안내를 통해 살펴본다.

## 두 개의 공간

### 비공개 작업소

- 자유 메모, 질문, 링크와 코드 조각
- 구조화된 실험과 실패 기록
- 실제 또는 민감한 문서
- 모델 설정, 실행 로그와 평가 결과
- 공개 전 검토와 비식별화

### 공개 전시실

- 해결하려 한 문제와 배경
- 핵심 개념과 설계 의도
- 공개 데이터 기반 기능과 서비스
- 모델과 접근 방식의 비교 결과
- 선별한 실패 사례와 배운 점
- 다음 학습 및 개선 방향

공개 첫 화면은 전체 화면 AI 연구소 월드다. 실제로 공개된 기술만 방으로 구성하고, 방 안에서
일하는 기술 관리자 캐릭터의 말풍선을 통해 기능과 설계·시행착오 상세 화면으로 이동한다.
연구하지 않은 기술의 빈 방은 미리 만들지 않는다.

두 공간은 저장소와 배포 환경을 분리한다. 비공개 데이터베이스를 공개 환경에 직접 연결하지 않으며, 사용자가 승인한 공개 패키지만 이동한다.

## 학습 자산의 생명주기

```text
자유 메모
  -> 구조화된 실험
  -> 검토와 비식별화
  -> 공개 결과물
```

자유 메모에는 형식을 강제하지 않는다. 구조화된 실험에는 목적, 가설, 데이터 스냅샷, 모델 프로파일, 실행 환경, 지표, 실패 사례와 결론을 기록한다. 공개 결과물은 원본 기록을 그대로 복사하지 않고 방문자가 이해할 수 있는 이야기로 재구성한다.

모든 원본 기록은 기본적으로 비공개다. 공개 수준은 다음 중 하나로 명시한다.

- 비공개
- 요약 공개
- 일부 공개
- 전체 공개

## 에이전트가 있는 작업소

에이전트는 기술 영역을 설명하고 실제 기능으로 안내하는 조직 구성원이다.

```text
작업소 총괄 에이전트
└─ 기술 영역 총괄 에이전트
   └─ 역할별 작업자 에이전트
```

화면의 캐릭터, 결정적인 Python 작업자, LLM 기반 실행 에이전트는 서로 다른 개념으로 관리한다. 캐릭터가 존재한다고 해서 모든 업무에 LLM을 사용하지 않는다.

## 첫 번째 기술 연구 영역

첫 번째 `Labs` 영역은 자산운용 전문 문서를 위한 RAG다. 초기 목표는 투자 판단이나 자동매매가 아니라, 권한이 허용된 문서에서 관련 근거를 찾아 원문 위치와 함께 보여주는 AI 검색이다.

초기 검색 기준선은 다음과 같다.

```text
BM25 + bi-encoder dense retrieval + RRF
```

LLM 답변 생성과 다중 에이전트 리서치는 검색 품질을 먼저 검증한 뒤 추가한다.

## 장기 확장 방향

RAG에서 검증한 학습, 실험, 모델 관리, 평가, 에이전트와 공개 절차를 이미지 생성, 음성, 컴퓨터 비전, 멀티에이전트 등의 새 `Labs` 영역에 재사용한다. 실제 연구를 시작하지 않은 기술의 빈 모듈은 미리 만들지 않는다.
