# ADR-0034: 검증된 답변의 주장별 텍스트와 인용 관계 보존

- 상태: 사용자 원인 수정 요청 범위의 결정, 구현·단위/본래 DB 검증 완료; 새 실제 모델 결과 검증은 진행 중
- 날짜: 2026-10-05
- 관련: [생성형 평가 경계](0030-rag-generative-evaluation.md), [실행 모니터링](0029-rag-execution-monitoring.md)

## 문제

현재 인용 검증기는 모델의 `GeneratedClaim`을 받아 주장별 근거 ID를 확인하지만 최종 답변은 주장 텍스트를 공백으로 합친다. 이후 평가 결과에는 합쳐진 답변과 주장 번호·근거 ID만 저장된다. 문장 구분자나 근거 ID에서 원래 주장 경계를 복원할 수 없다. 따라서 한 답변의 일부 인용이 누락됐다고 단정하거나 이를 통과 증거로 사용할 수 없다.

실제 합성 Q14 후속 답변의 본문·원문 사실은 맞았으나, 주장 경계를 추론해 내린 잠정 실패 판정은 철회했다. 과거 실행·결과 digest·검토를 보충하거나 재작성하지 않는다.

## 결정

- 성공한 `CitationValidator`가 만드는 `GeneratedCitation`에 검증 입력의 `claim.text`를 `claim_text`로 그대로 보존한다. 합쳐진 답변은 종전과 같다. 문장 분할·키워드 추론·다른 모델 호출을 사용하지 않는다.
- 일반 검색/대화의 `GeneratedCitationResponse`, 비공개 평가의 `ClaimCitation` 및 소유자 전용 `GenerativeAttemptView.claim_citations`에 같은 정보를 연결한다. 기존 권한·원문 READY·범위 재검증 경로를 유지한다.
- 과거 자료의 `claim_text`는 없음을 허용한다. 평가 비공개 결과 및 검색 응답 직렬화에서는 값이 없으면 이 새 키를 생략하여 기존 canonical bytes와 digest·응답 형태를 유지한다. 새 텍스트가 있으면 결과 digest에 포함해 판정을 정확한 주장·근거 묶음에 결속한다.
- 비교 실험의 검토 영역에서 기본 접힌 `주장별 인용 근거`를 제공한다. 정확한 주장 텍스트와 해당 근거 원문 링크를 보여주고, 과거 자료의 경계 미기록은 명시한다. 보기만으로 평가·외부 모델 호출·판정 등록을 하지 않는다.
- 주장 텍스트는 이미 승인된 최종 답변 데이터의 일부다. 비공개 DB/API 밖의 로그나 비공개 내부 추론으로 저장하지 않는다. 외부 전송·모델·지침·평가 정책은 변경하지 않는다.

## 검증 범위

다중 문장과 문장 중간 접속을 포함한 주장도 원래 경계대로 왕복해야 한다. 과거 결과의 직렬화·digest·판정 결속은 실제 본래 DB에서 읽기 전용으로 대조한다. 새 주장 텍스트가 바뀌면 digest가 달라져야 한다. UI는 근거 위치의 구조 검증과 의미 검토를 구분하고, 미기록 상태에서 경계를 만들어 표시하지 않는다.

이 결정은 구조 검증을 의미적 함의 검증으로 확대하지 않는다. 실제 모델 답변의 정답·인용 의미는 원문 검토와 별도 평가로 확인하며, 근거 예산 후보는 저장된 정상 승격 조건을 충족하기 전까지 대화에 활성화하지 않는다.
