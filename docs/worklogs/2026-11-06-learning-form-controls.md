# 학습 작성기 참조 정렬과 체크박스

## 요구와 범위

관련 참조의 선택란·추가 버튼이 라벨을 포함한 가운데 정렬로 어긋나던 배치를 조작부 하단 기준으로 맞춘다. 긴 참조 제목과 삭제 버튼은 좁은 폭에서도 읽을 수 있도록 배치한다.

체크박스는 공통 컴포넌트로 제공하고 학습 작성기의 기술 주제·실험 항목·문제 해결·학습 흐름 선택에 적용한다. 실제 native input의 라벨·키보드·disabled 의미를 유지하면서 선택·hover·focus를 구분하고 라벨의 클릭 영역을 확보한다. 기존 토큰과 두 테마를 재사용하며 디자인 시스템에 실제 컴포넌트 견본을 추가한다.

전체 사이트에 일괄 적용하거나 저장/API/모델 동작을 바꾸지 않는다. 기존 미커밋 UI와 다른 세션 학습 변경을 보존한다. 구현과 독립 코드·실제 화면 검증을 분리한다. 문제 이력 DB 쓰기는 앞선 승인 거절 범위이므로 재시도하지 않는다.

## 검증

- 구현 담당의 학습 기능 전체·공통 체크박스·디자인 시스템 17개 파일 100개 테스트 통과. 전체 TypeScript와 변경 TS/TSX ESLint 통과. 이번 변경의 프로덕션 빌드는 미실행이다.
- 메인의 독립 체크박스·기존 실험 항목 토글·디자인 시스템 회귀 3개 파일 9건 통과. 라벨 클릭·Space·native FormData·직접 및 fieldset disabled를 확인했다.
- 독립 코드 검토에서 기호와 라벨의 그리드 정렬, 색만 의존하지 않는 체크 표시, fieldset 비활성화와 forced-colors의 native 표시 복귀를 확인했다.
- 본래 Chrome에서 참조 선택란·추가 버튼의 데스크톱 하단 좌표가 같고 높이가 약 44px인 것을 확인했다. 라이트·다크 320px에서 참조 행이 세로 배치되며 가로 넘침이 없었다. 작성기 입력·저장은 하지 않았다.
- 디자인 시스템에서 라벨 클릭·Space 전환, 청록 포커스·보라 선택·체크 기호, disabled의 선택 유지와 Tab 건너뛰기, hover 배경을 실제 확인했다. 두 테마 desktop/320px에서 긴 라벨의 첫 줄 정렬·줄바꿈과 넘침 없음을 확인했다. 고대비 모드 실행 검증은 브라우저 도구 미지원으로 미실행이며 CSS fallback 코드만 검토했다.
