# 공개 연구 기록 카드 전체 링크

## 승인 범위

사용자가 카드 전체 hover·클릭 이동과 별도 `기록 읽기` 버튼 제거를 승인했다.
공개 목록 카드 하나당 실제 Next Link 하나로 구성하여 제목·요약·주제·여백을 모두 클릭 가능하게 한다.
Tab/Enter·focus-visible, 기존 topic/page URL과 상세 복귀를 유지한다.
상세의 돌아가기 버튼, 관리자 UI, 서버 API와 공개 데이터는 변경하지 않는다.

## 구현과 검증

프론트/TDD 담당과 메인 실제 브라우저 검증을 분리한다. 변경 전 파일은 작업별 임시 영역에 보관한다.
카드 hover·여백 클릭·단일 링크·키보드 이동·선택 상태 복귀와 좁은 화면을 확인한다.
변경 전 실패 2건을 확인한 뒤 구현했다. 메인 재검증에서 Publishing·공개 경로 10개 파일
66개 테스트, TypeScript와 관련 ESLint가 통과했다.

실제 Edge 1440/390px에서 카드 단일 링크·여백 클릭·hover 배경/테두리 변경,
Tab/Shift+Tab 포커스·Enter 이동과 카테고리 URL 복귀를 확인했다. 가로 넘침과 브라우저 오류는 없었다.
카드 스타일은 공개 목록에서만 사용되며 상세 돌아가기 버튼은 유지했다.
새 의존성·서버·데이터 변경과 커밋·푸시는 없다. 이번 작은 UI 수정에 별도 production build는 실행하지 않았다.

후속 사용자 요청으로 제목 hover의 밑줄 선언만 제거했다. 실제 브라우저에서 computed
text-decoration이 underline인 실패를 먼저 확인한 뒤 none으로 바뀐 것을 검증했다.
1440/390px 카드 전체 클릭·hover 강조·키보드·복귀 회귀 검증도 통과했다.
