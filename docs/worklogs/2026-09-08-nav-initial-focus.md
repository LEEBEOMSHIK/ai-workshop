# 공개 nav 정렬과 메인 최초 이동

## 승인 범위

연구 기록 목록·상세의 nav를 `/labs/rag`의 전체 너비 bar, 배경, 하단 구분선,
여백·메뉴 색상에 맞춘다. 기존 읽기 링크·본문 표시와 관리자 UI는 유지한다.
메인 게임은 준비 완료 시 최초 한 번 canvas에 포커스를 주어 클릭 없이 이동하게 한다.
로딩 중 메뉴 선택, 입력, 창 이탈 등 사용자의 의도가 있으면 자동 포커스를 포기한다.
대화·메뉴·숨김 탭에서 이동 금지와 수동 이동 복귀는 보존한다.

프론트/TDD 구현과 메인 브라우저 검증·독립 리뷰를 분리한다. main에서 작업하며
새 라이브러리·API·DB·모델·권한·게시 데이터 변경은 없다.

## 검증

- 변경 전 실제 Edge: 세 화면 폭의 nav 불일치와 최초 포커스·무클릭 이동 실패를 확인했다.
- TDD 초기 포커스 테스트 2건 실패를 확인한 뒤 9건 통과. 관련 office-game·Publishing
  전체 68개(11개 파일), 타입 검사·전체 ESLint 통과.
- 실제 Edge 1440/960/390에서 목록·상세 nav의 위치·너비·높이·여백·배경·테두리·링크
  색상을 `/labs/rag`와 대조해 일치를 확인했다. 가로 넘침 없음.
- 메인 무클릭 WASD 이동, 메뉴 포커스 중 이동 차단, 지연한 맵 로딩 중 메뉴 선택 보존,
  수동 canvas 포커스 복귀를 실제 브라우저에서 확인했다. 최종 issues 0건.
- 기존 E2E 2건 통과(28.8초): NPC 대화·이동 잠금·닫기 복귀, 벽 충돌·포커스 이탈·resize·경로 재진입.
- production build 종료 0. 기존 publishing-build 인스턴스를 재사용했다. Next가 생성한
  임시 타입 경로만 복구했고 이후 타입 검사·전체 lint 명령도 종료 0을 확인했다.
- 독립 리뷰: 기존 4개 파일과 신규 helper·테스트를 대조해 결함 없음으로 승인했고,
  초기 포커스 9개 테스트를 별도 실행해 통과했다.

## 변경 파일과 인계

- Publishing.module.css / PublicStudies.tsx: 공개 전용 shell로 full-width nav와 본문 여백 분리.
- GameClient.tsx / initialFocus.ts: 비동기 런타임 생성 전 일회성 초기 포커스 준비·취소·정리.
- initialFocus.test.ts: 즉시 이동, 사용자 선택, blur·숨김·대화, 재마운트 회귀.
- OfficeOverlay.tsx: 클릭 필수 안내를 선택적 이동 복귀 안내로 수정.
- 로컬 실행서의 시작 안내와 WORKBOARD를 갱신했다. 실제 데이터·서버·캐시는 보존했다.

사용자는 `/`를 새로 열고 로딩 완료 후 클릭 없이 WASD/방향키를 확인한다. 먼저 메뉴를
선택했거나 창을 떠났다면 자동 포커스가 취소되는 것이 정상이며 화면 클릭으로 복귀한다.
`/labs/rag/studies`와 상세 nav는 `/labs/rag` 기준이다. 커밋·push는 하지 않았다.
