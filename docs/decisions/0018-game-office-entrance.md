# ADR-0018: 공개 입구의 게임형 연구소

- 상태: 승인됨 — 2026-09-07 사용자 상세 요구에 따른 MVP 구현

## 결정

Next.js App Router의 `/`만 게임형 공개 입구로 전환한다. 기존 `/labs`, RAG,
작업소, 관리자 화면과 인증은 보존한다. Phaser 4는 브라우저에서만 실행하며
하나의 OfficeScene에서 타일 맵, 이동, 충돌, 카메라, NPC 접근을 담당한다.
React는 메뉴와 접근 가능한 대화창을 담당한다. 세션별 Zustand vanilla store를
작은 상태 브리지로 사용하며 Scene이 React 컴포넌트를 참조하지 않는다.

Tiled 호환 JSON 맵의 공간/충돌/상호작용/NPC 배치를 데이터로 관리한다.
로비와 LLM 연구실, 플레이어와 LLM Lead 한 명만 구현한다. 그래픽은 교체 가능한
코드 생성 placeholder이며 참고 이미지를 배경으로 복제하지 않는다.
따뜻한 바닥·식물과 푸른 연구 장비로 방의 역할을 구분한다.

Phaser와 Zustand만 런타임 의존성으로 추가한다. Tailwind/PostCSS는 사용자 요청에
따라 추가하되 preflight를 제외하고 접두사를 사용해 기존 화면 스타일을 보호한다.
Playwright는 개발 전용 검증 의존성으로 사용하며 설치된 브라우저로 실제 입력을 검사한다.
Phaser 인스턴스는 클라이언트 마운트에 귀속되며 비동기 로드 취소, resize,
destroy와 입력 해제를 보장한다. 대화창, 포커스 이탈, 숨김 탭에서는 이동하지 않는다.

## 경계와 영향

- Canvas에는 업무 폼이나 실제 AI 호출을 넣지 않는다.
- NPC 설명은 정적 공개 안내이며 기존 공개 RAG 연구실로 연결할 수 있다.
- 위치는 서버에 저장하지 않으며 비공개 데이터/인증과 연결하지 않는다.
- 방·NPC·자산·튜닝 상수는 분리한다. 전체 연구실과 AI runtime은 후속 작업이다.
- 단위 테스트와 실제 브라우저 키보드·충돌·대화·리사이즈 검증을 구분한다.
- 상세 실행 계획: [게임 입구 MVP](../superpowers/plans/2026-09-07-game-office.md).

## 승인된 후속 확장 — 2026-09-07

사용자는 기존 LLM 표기 대신 RAG 총괄이 RAG 공간에서 자신의 연구소로 안내하고,
사장실에 LEE BEOMSHIK / Founder가 연구 방향을 지시하는 공개 소개 경험을 승인했다.
기존 한 OfficeScene에 사장실·로비·RAG 공간을 연결한다. Founder는 방문자 플레이어와 별개다.
등록된 NPC 클릭 또는 기존 근접 E로 React 대화를 열고 RAG 총괄의 명시적 입장 버튼은
기존 `/labs/rag`로 연결한다. 이 경로의 React 작업실은 기존 여섯 담당자와 공개 설명을
보존하면서 공간·작업대·캐릭터 표현을 개선하며 새 Phaser Scene으로 대체하지 않는다.

지시는 공개 연구 방향을 보여주는 정적 연출이며 실제 명령 전송·진행률·성공 이력이 아니다.
새 AI 호출, 비공개 기록 조회, 모델 설정 및 인증 변경은 없다. 사용자 이메일은 공개하지 않는다.
분리된 타일·가구·캐릭터 자산으로 질감/입면/그림자를 개선하며 통배경 이미지는 사용하지 않는다.

## 승인된 준비 공간 — 2026-09-07

사용자가 파인튜닝 연구소·AI 공부실·온톨로지 연구소를 맵에 추가하고 `관리자 모집 중`으로
두는 것을 명시 승인했다. 같은 OfficeScene의 연결된 공간이며 들어가 둘러볼 수 있다.
각각 학습 장비/모니터, 책장/노트/화이트보드, 지식 관계도 보드로 구분한다.
담당자 NPC 대신 빈 작업대와 모집 안내판을 둔다. 클릭 또는 근접 E는 공간 목적과
`관리자 모집 중 · 기능 준비 중`이라는 React 안내만 열고 서비스 링크·채용 신청·AI 실행은 제공하지 않는다.

준비 공간 메타데이터와 안내 대상을 NPC·운영 서비스와 구분한다. 이 승인은 맵의 표현만
추가하며 미래 Lab의 backend 폴더·API·라우트·가짜 작업 이력을 만드는 승인이 아니다.
기존 비공개 Learning과 모델 실험 코드는 유지하되 이 공간으로 자동 연결하지 않는다.
기존 Founder/RAG 이동·충돌·대화·직접 연구소 입장과 브라우저 수명주기를 회귀 검증한다.

## 공개 연구실 목록 역할 정리 — 2026-09-08

사용자 승인에 따라 `/labs`는 기술 연구실 빠른 선택 목록으로 정리한다. `/`의 게임형 본사와
`/labs/rag`의 기술별 작업 현장은 유지하며, 목록에서 RAG 공정을 모든 기술에 반복하지 않는다.
공개 카탈로그의 실제 연구실은 상세로 연결하고 기존 세 준비 공간은 비활성 안내로만 제공한다.
공개 nav는 기술 상세·연구 기록과 동일한 공통 스타일을 사용한다. 인증·게임·API 경계는 변경하지 않는다.
