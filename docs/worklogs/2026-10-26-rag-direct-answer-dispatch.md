# 첫 응답의 중복 위임 호출 제거 — 2026-10-26

## 목적과 선택 근거

현재 답변 품질을 유지하며 첫 응답의 불필요한 일을 줄인다. 기존 실행 `cc82e756-b56b-44c1-951d-b7c4174e6178`의 첫 전체210.948초·답변 담당 입력 처리134.925초를 기준으로 조사했다. v6 입력은 이미 공유 출처·짧은 인용 ID·행 배열을 사용한다. 추가 좌표 사전은 설명 전 최대61B만 줄여 채택하지 않았다. 실행 배치·스레드 조정도 현재 실효값과 효과가 미확인이라 이번 변경에서 제외했다.

관측된 공개 질문의 두 반복에서 관리자 `delegated_task`가 원질문·resolved_query와 정확히 같았다. 관리자가 보탠 정보는 없었다. 첫 관리자26.046초 중 로드13.331초·입력9.783초·출력2.440초이며 반복은3.526초다. 로드는 답변 담당으로 이동할 수 있어26초 전체를 절감량으로 계산하지 않는다.

## 구현 계약

[ADR-0046](../decisions/0046-rag-direct-answer-dispatch.md)의 `orchestration.dispatch_mode=direct_answer`는 애플리케이션이 원질문을 작업으로 지정하고 동일 SDK 답변 담당을 한 번 실행한다. 생략 시 기존 `manager_delegation` 경로를 유지한다. 같은 지침·원질문·resolved_query·이력·근거·schema·인용 복원·모델·출력 한도를 사용한다. 직접 경로의 실제 모델1회·도구0회, agent/model 두 단계를 기록한다. 기존 경로는 모델2회·도구1회와 다섯 단계다. 선행 문맥화와 총예산, ACL 재확인·실패·취소·종료 추적은 유지한다.

제품 구현과 독립 검증을 완료했다. 관리자가 다른 작업을 작성하는 질문까지 입력이나 답변이 동등하다고 주장하지 않는다. 일반 기본값은 바꾸지 않으며 실제 검증 전 후보를 승격하지 않는다.

### 답변 보존·권한·환경 검증

두 실행 모두 기존과 지침·agent 입력·실제 HTTP 입력·관측된 답변 JSON·최종 답변·인용이 정확히 같다. 전체28근거의 원문·출처·위치·순서·eN→UUID 변환표도 독립 역변환에서 동일하다. 실제 trace는 각 answer_specialist agent와 model 두 단계이며 관리자/위임은0회다. 현재 소유자 ACL 상세 조회는 성공하고 다른 actor는 거부됐다. 실행 기록의 본문 무결성과 세부 연산 지표도 일치한다.
