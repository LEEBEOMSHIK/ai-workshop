# RAG 대화 테두리와 상하 여백 보정

- 날짜: 2026-09-27
- 관련 문제: ISSUE-00010 후속 화면 배치 보정
- 상태: 구현·본래 마스터 화면 검증 완료

## 원인과 수정

기존 대화 패널은 어두운 배경에 가까운 #2a3742 테두리, 내부 여백0px와 입력부 간격3.2px를 사용했다.
공통 셸 아래에서 상하단과 입력 컨트롤이 붙어 보인다는 사용자 지적을 실제 대화 화면에서 확인했다.

- 패널·입력부 경계를 #586b7d 공통 CSS 변수로 지정하고 입력부에 배경과 둥근 테두리를 추가했다.
- 바깥 여백은 PC24px·모바일16px, 패널 내부는 PC12px·좁은 화면8px로 조정했다.
- 패널 및 입력부 항목 간격8px, 입력부 세로 여백12px를 적용했다.
- 대화 내용의 flex 확장, 원문·문서 추가 팝오버, 기존 동작과 권한을 유지했다.

## 검증

- 본래 로그인된 마스터의 자산운용 대화 화면에서 수정 전후 스타일·스크린샷 비교.
- 1440×741: 대화 내용307px, 입력부187px. 테두리 대비·상하 여백 확인.
- 390×844: 대화 내용309px, 입력부265px, 화면 하단 약16px 여백·가로 넘침 없음.
- 1100×800: 대화 내용327px, 입력부226px, 하단 약20px 여백·가로 넘침 없음.
- 모바일 + 문서 추가 팝오버가 화면 안에 표시되고 잘리지 않음.
- 대화·첨부 기존 회귀 테스트43건, TypeScript, diff 공백 검사 통과. 독립 CSS 검토 차단 사항 없음.
- 새 질문·첨부·세션 생성을 하지 않았다. 실제 모바일 기기와 화면 키보드 검증은 포함하지 않았다.
- 낮은 가로 화면의 기존 최소 높이 정책은 유지하며 세로 스크롤을 허용한다.

## 이전 작업 검증 보완

앞선 전체 메뉴 적용에서 대기했던 마스터 로그인이 확인되어 RAG 대화 화면의 공통 메뉴와 본문 배치도 검증했다.
파일함·학습 화면의 실제 재검증 및 공개 연구 서비스 오류 확인은 별도 남은 항목으로 유지한다.
