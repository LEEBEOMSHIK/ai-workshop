# 탐색기 최상위 표현과 폴더 스타일

사용자 승인으로 미분류 표시를 제거하고 null 위치를 파일함 최상위로 표현했다.
실제 root/test 등 폴더는 일반 폴더로 그대로 보존한다. 파일/폴더 이동·병합·이름 변경·DB 변경은 하지 않았다.

## 변경

- LibraryTree: inline SVG 폴더/펼침 아이콘, 선택 행, 계층 안내선과 일관된 들여쓰기.
- DocumentBrowser: 제목·breadcrumb·저장 위치의 최상위 문구 통일. 기존 관리 동작은 보존.
- CSS: 기존 파일함 색상 토큰과 scoped 스타일 사용. 이미지/패키지 추가 없음.
- 테스트: 키보드로 null 최상위와 실제 root ID가 별개임을 검증. 기존 권한·펼침·목록 회귀 유지.

## 검증

- 초기 RED: 새 최상위 이름이 없어 새 키보드 테스트·범위 제한 테스트 실패.
- 구현 담당 assets/domain/panel8파일75건 통과, typecheck·전체lint 통과.
- 메인 tree/browser/management3파일44건 재실행 통과(55.13초).
- 독립 코드 리뷰 차단 없음. 브라우저 로그인 상태에서 아이콘/선택 행/최상위 문서 및 실제 root/test 분리 확인.
- 사용자 자료·references 이미지·기존 미커밋 관리 변경을 보존했다.

## 남은 범위

드래그앤드롭과 이동 메뉴는 아직 제공하지 않는다.
[이동 상세 설계](../superpowers/specs/2026-09-13-explorer-movement-design.md)는 독립 검토를 반영했으며 사용자 문서 확인 대기다.
설계 확인 후 서버 metadata revision·이동 계약·검색 정합성·UI 연결 실행 계획으로 진행한다.
