# 업무 화면 실제 점검과 디자인 시스템 후속 수정

2026-10-26 사용자의 나머지 업무 화면 확인·수정 요청을 이어서 수행했다. 이전 turn의 Windows 네이티브 브라우저 URL 식별 중단 이후 Chrome 탭 연결을 다시 확인했고, 본래 로그인 계정과 기존 자료로 화면을 점검했다. 기존 다크·청록 방향과 [적용 설계](../superpowers/specs/2026-10-26-design-system-adoption-design.md)를 유지했다.

작업은 중간 위험의 UI 변경으로 분류했다. 메인이 실제 브라우저·공통 CSS·문서 통합을, 두 구현 담당이 파일함 링크와 문서 선택 모달을, 별도 담당이 회귀·타입·린트·보존 검사를 맡았다. 모델·검색·권한 정책·DB 스키마 역할은 변경 범위가 없어 제외했다. 공개 연구 연결 오류 발견 후 백엔드·로컬 실행의 읽기 전용 진단 역할을 추가했다.

## 본래 화면에서 확인한 범위

이번 실제 화면은1920px 데스크톱이다. 목록 진입만으로 전체 기능을 검증했다고 세지 않고, 확인한 상태를 구분한다.

관측한 관리 화면은36px 산세리프 제목·컨트롤44px 기준·페이지 가로 넘침 없음이었다. 대화의 좁은 제목과 원문 읽기 제목은 기존 의도된 예외다. 일반 본문 링크와 숨겨진 details 내부를 모든 작업 버튼과 동일하게 집계하지 않았다.

본래 앱의375px iframe 검사를 시도했으나 내부 문서가about:blank로 남아 모바일 성공 증거로 사용하지 않았다. 임시 loopback helper는 종료했고 진단 파일은 작업 증거 디렉터리로 옮겼다. 이전 [첫 적용 작업](2026-10-26-design-system-adoption.md)의320/375/1280px 대표 합성 검증과 이번 데스크톱 실제 검증을 구분한다.

## 별도 관측과 남은 범위

- 실행 목록은 첫 확인에서30초 이상 로딩이 유지됐고, 이후 새 탭에서 정상 목록과 다음 페이지 버튼이 표시됐다. 정확한 응답 시간은 계측하지 않았다. 개별 상세는 정상이다. 소스상 전체 대화 의존 관계의 현재 권한 검사와 전체 평가 상세 복원 이후 필터/제한이 적용되는 경로가 원인 후보다. UI 수정으로 해결됐거나 무한 로딩이라고 단정하지 않는다. 현재 권한을 생략하는 수정은 하지 않았다.
- 공개 연구 목록 오류는 공개 reader의18001 포트 미리스닝으로 확인했다. 기존 공개 SQLite가 존재하고 private API·프론트는 정상인 상태였다. 독립 검토 뒤 기존 Python 환경의 `ai_workshop.public_app:app`을127.0.0.1:18001에만 기동했다. 기존 프로세스 재시작이나 새 DB 생성 없이 공개 조회를 복구했다. 상속 환경은 지우고 Windows 런타임 필수 값과 `AI_WORKSHOP_PUBLIC_STORE_PATH`의 기존 절대 경로만 전달했으며 루트.env·비공개 DB/모델 비밀값은 주입하지 않았다. reader는 `mode=ro`·`query_only`를 사용한다.
- 복구 후 공개 health 정상·catalog 응답·본래15개 목록을 확인했다. 기존 SQLite SHA-256 `486498eea52c908d176a54f348f55a0c7c0c2edbe7174746477aed7c88fad7ba`는 동일했다. 운영 증거는 `public-reader-restoration.json`과 `public-reader-acceptance.json`이다. 창 숨김·access log 비활성·자동 reload 없음이며 서비스는 사용자가 공개 화면을 계속 사용할 수 있게 유지했다. 같은 Windows 계정의 실행은 운영 OS 권한 격리를 증명하지 않으며 재부팅 뒤 자동 기동을 새로 구성한 것은 아니다.
- 로그인/최초 설정, 자료 없는 학습 상세, 모든 오류·권한·모달 조합, 전체 모바일 수용은 이번 확인 범위에 포함되지 않는다.
- 모델 호출0회이며 기존 첫 입력 처리 시간과 정답0/2 한계를 유지한다. UI 회귀 통과를 답변 품질 개선이나 새 모델 비교 결과로 해석하지 않는다.

운영 이력은 기존 [ISSUE-00040](http://127.0.0.1:5173/admin/system/issues?issue=80d1511b-5f95-4afc-b8b2-b06df458c4c9)에 후속 수정·독립 검증·실제 화면 범위와 제한을 보존한다. 본 Markdown은 저장소 기록이며 DB 문서 버전으로 별도 등록한 것은 아니다. 설치·기본 설정 승격·commit/push는 수행하지 않았다.

원인이 다른 공개 reader 장애는 [ISSUE-00041](http://127.0.0.1:5173/admin/system/issues?issue=f68fa6e6-a80c-4f0d-8aa4-89d232fbe766)의 검증 완료로, 실행 목록 지연은 [ISSUE-00042](http://127.0.0.1:5173/admin/system/issues?issue=fd3f7922-c3a6-4c8f-8647-b2ff1a7ff0e0)의 진행 중으로 분리했다. 저장 후 본래 화면에서 다시 조회했다. 목록 후속은 실제 단계별 시간/쿼리 수 계측→현재 ACL과 의존관계를 보존한 일괄 조회/중복 조회 제거→목록에 불필요한 전체 상세 복원 분리→정렬/페이지/전체 건수 및 본래 지연 재검증 순서다. 이 backend 최적화를 이번 UI 완료 범위로 보고하지 않는다.
