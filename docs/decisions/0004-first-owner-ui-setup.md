# ADR-0004: 최초 소유자는 로컬 설정 UI에서 생성한다

- 상태: 승인됨
- 결정일: 2026-09-02

## 배경

첫 버전은 관리자 한 명을 지원하지만, 일반 사용 흐름이 터미널 명령에 의존하면 계정 생성
위치와 기본 지식 공간 준비 여부를 UI에서 알 수 없다. 동시에 두 설정 요청이 들어와도 소유자
한 명이라는 계약이 깨지면 안 된다.

## 결정

관리자가 없는 로컬 환경은 공개 상태 API와 `/setup` 화면을 제공한다. 최초 설정은 소유자,
전사 지식 공간과 개인 연구 공간을 하나의 PostgreSQL 트랜잭션에서 생성하고 세션을 발급한다.
소유자 생성 직전 `users` 테이블을 잠가 동시 요청을 직렬화하며, 기존 소유자가 있으면 설정을
거부한다.

보호 경로는 미인증 상태에서 설정 필요 여부를 확인해 `/setup` 또는 `/login`으로 보낸다.
설정 완료 뒤 `/setup`은 로그인으로 이동한다. CLI bootstrap은 UI를 사용할 수 없는 복구
수단으로만 유지하며 같은 중복 방지와 기본 공간 생성 계약을 사용한다.

## 결과

### 장점

- 사용자는 웹에서 초기 설정 위치와 생성 결과를 명확히 확인한다.
- 부분 생성과 동시 소유자 생성을 방지한다.
- 초기 설정 직후 별도 로그인 없이 지식 공간으로 이동한다.

### 비용

- 인증 전 공개 API가 추가되므로 소유자 존재 여부만 제한적으로 노출한다.
- PostgreSQL 잠금에 의존하는 저장소 구현을 별도 테스트해야 한다.
