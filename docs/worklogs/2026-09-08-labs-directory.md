# 공개 연구실 선택 목록

## 승인된 역할

- `/`: 플레이어가 이동하는 회사·연구소 본사.
- `/labs`: 공개 기술 연구실을 빠르게 선택하는 목록.
- `/labs/rag`: RAG 책임자·작업 파이프라인·기능 소개.

기존 `/labs`가 모든 기술에 RAG 공정을 반복하던 표현을 제거한다. 검증된 공개 카탈로그에서
연구실 이름·상태·설명·책임자와 상세 경로를 사용한다. 기존 준비 공간은 준비 상태로 표시하고
아직 없는 상세 페이지에 링크하지 않는다. nav는 기존 RAG·연구 기록의 시각 기준으로 통일한다.
게임 화면·인증·서버·공개 기록 데이터 변경은 없다.

## 검증 계획

프론트/TDD 구현, 메인 브라우저·타입/린트·회귀 테스트, 독립 코드 리뷰를 분리한다.
목록·진입·준비 카드·빈 목록/오류, 1440/390px 공개 nav 비교와 상세 화면을 확인한다.

## 완료 결과

- `LabWorldPage.tsx`와 신규 `LabDirectory.module.css`가 기술별 목록·준비 카드를 담당한다.
  기존 순수 `preparingRooms` 메타데이터만 재사용하며 Phaser나 게임 런타임을 불러오지 않는다.
- `PublicNavigation.module.css`로 공통 header 스타일을 모으고 PublicLabScene·Publishing의
  중복 nav 규칙을 제거했다. 링크 색상·배경·여백·포커스를 기존 RAG 기준으로 유지했다.
- 실패 3건 확인 후 집중 테스트 8개 통과. 메인 재검증은 22개 파일 143개 테스트,
  TypeScript·전체 ESLint·production build가 통과했다. build 전용 타입 경로를
  기존 dev 경로로 되돌린 뒤 TypeScript 재검증도 통과했다.
- 실제 Edge 1440/390px에서 `/labs`, `/labs/rag`, `/labs/rag/studies`, `/login`의
  nav computed style이 같음을 확인했다. 준비 카드의 비활성 상태, 키보드 RAG 진입·목록 복귀,
  가로 넘침 없음과 브라우저 오류 0건을 확인했다.
- 독립 코드 리뷰에서 수정이 필요한 결함은 없었다. 인증·API·데이터·게임 HUD 변경은 없으며
  새 패키지 설치·커밋·푸시도 하지 않았다.

사용자 확인: `/labs`에서 공개 RAG 카드와 세 준비 공간, nav를 확인하고 RAG 카드로 진입한다.
