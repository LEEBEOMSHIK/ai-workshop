# ADR 0015: 도메인 서비스 연결과 대화 범위를 명시적으로 결합한다

- 상태: 승인됨 / 구현 반영, 실제 서비스 연결은 관리자 선택 후 검증
- 기준일: 2026-09-07
- 상세 계약: [도메인 선택 후 대화형 RAG](../superpowers/specs/2026-09-07-domain-first-rag-conversation-design.md)

## 맥락

기존 사용자 검색 화면은 저장 구성·지식공간·폴더 선택을 중심으로 구성되어 있다.
사용자는 저장 위치가 아니라 전문 도메인을 선택해 대화에 진입해야 한다. 도메인은
자산운용에 한정되지 않으며 관리자 등록으로 확장할 수 있어야 한다.

## 결정

RAG 모듈에 도메인과 불변 서비스 연결 버전을 둔다. 연결 버전은 정확한 저장 RAG 구성
버전과 허용 공간을 참조한다. 관리자가 평가 통과·생성 준비 조건을 만족한 연결을 명시적으로
활성화하며, 프론트는 도메인이나 모델 목록을 고정하지 않는다.

도메인은 권한을 추가 부여하지 않는다. 도메인·구성·사용자 권한의 교집합을 매 검색에
검증하고 실제 요청자의 권한으로 검색과 원문 조회를 수행한다. 기존 개인 구성의 직접 조회
권한과 외부 전송 승인 계약은 유지한다.

대화는 연결 버전을 고정한다. 공간·폴더 변경 시 기존 메시지는 남기되 다음 질문부터 새
문맥 구간을 시작한다. assistant 서명은 사용자·구성·연결 버전·정규화한 검색 범위를 결합한다.
연결 변경이나 폐기, 권한 회수는 명시적인 재진입 요구로 처리한다.

## 결과

- 사용자 입구에는 도메인 선택, 대화 안에는 검색 범위와 근거 확인, 관리자 화면에는 연결
  설정을 둔다. 도메인과 저장 위치를 혼동하지 않는다.
- 도메인 최초 등록은 관리자의 실제 구성·공간 선택이 필요하다. 기존 문서를 자동 분류하거나
  예시 도메인을 생성하지 않는다.
- 범위 변경 전 대화를 새 범위의 LLM 입력으로 재사용하지 않으므로 문맥 구간 안내가 필요하다.
- 대화 영속 저장·공개 검색·인라인 첨부·피드백 학습은 별도 후속 구현으로 유지한다.
