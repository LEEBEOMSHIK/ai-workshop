# 학습 기록 필터 도구 모음

## 요구와 범위

목록보다 크게 드러나던 검색 조건을 정리한다. 정렬·페이지당 표시를 간결한 도구 모음에 유지하고, 주제·기록 종류·보관 상태는 기본 접힌 상세 필터에서 선택한다. 선택 조건은 접혀 있어도 요약으로 표시한다.

## 수용 기준

- 상세 필터 열기·닫기는 조회 조건과 현재 페이지를 바꾸지 않는다.
- 조건 변경은 기존처럼 첫 페이지로 돌아간다. 초기화는 주제·종류·보관 조건만 기본값으로 돌리고 정렬과 페이지 크기를 유지한다.
- 기본 보관 조건이 현재 기록임을 알 수 있어야 한다. 적용 중인 비기본 조건과 초기화 동작을 구분한다.
- 공통 선택 필드·펼침 및 의미별 색·간격 토큰을 사용하고 두 테마·좁은 폭·키보드 동작을 유지한다.
- 기존 새 기록 작성과 카드 전체 이동, 다른 세션 학습 작업, API·DB는 변경하지 않는다. 구현과 독립 검증을 분리한다.

## 검증

- 신규 2건은 변경 전 실패를 확인했다. 관련 4개 파일 30건, 메인의 독립 필터·작성·카드 이동 회귀 3개 파일 8건 통과.
- 전체 TypeScript와 대상 ESLint, 디자인 시스템 페이지 ESLint, diff 공백 검사 통과.
- 독립 코드 검토에서 조회 상태와 펼침 상태 분리, 초기화의 정렬·크기 보존, hidden 패널의 기본 접힘과 제목 기반 컨트롤 이름을 확인했다. 프로덕션 빌드는 이번 변경에서 실행하지 않았다.
- 본래 Chrome에서 기본 접힘 도구 모음, 적용 조건 2개 요약·개수, 접었다 펴기 값 유지, 보관 조건까지 초기화하면서 정렬·10개 유지, Enter/Space 펼침과 숨긴 선택 필드의 Tab 제외를 확인했다.
- 다크 375/320px·라이트 320px에서 가로 넘침이 없었다. 데스크톱 접힌 화면도 시각 확인했고, 기존 다크·기본 폭·최신순·5개·상세 접힘·모든 주제/종류·현재 기록으로 복원했다. 저장된 학습 데이터는 변경하지 않았다.
- ISSUE-00051 후속 이력 저장은 자동 승인 심사가 UI 수정 요청에 영구 이력 추가 승인이 포함되지 않았다고 판단해 차단했다. 우회·재시도하지 않았으며 DB 이력 반영은 미완료다.
