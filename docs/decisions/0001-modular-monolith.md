# ADR-0001: 모듈형 모놀리스로 시작한다

- 상태: 승인됨
- 결정일: 2026-08-29

## 배경

AI Workshop은 공통 플랫폼과 여러 AI 연구 영역을 장기적으로 포함한다. 첫 연구 영역인 RAG만으로도 문서 처리, 검색, 모델 실험, 에이전트와 공개 기능이 필요하다.

처음부터 에이전트별 마이크로서비스를 만들면 분산 배포, 네트워크 오류, 데이터 일관성과 관찰 가능성을 먼저 해결해야 한다. 에이전트 프레임워크를 전체 구조의 중심에 두면 핵심 검색 동작이 프레임워크 추상화에 가려질 수 있다.

## 결정

React 프론트엔드와 FastAPI 백엔드를 사용하는 모노레포의 모듈형 모놀리스로 시작한다. 긴 작업은 같은 Python 모듈을 공유하는 별도 워커 프로세스가 실행한다.

공통 플랫폼과 `Labs/RAG`를 명확한 모듈 경계로 분리하고, 외부 시스템은 어댑터를 통해 호출한다.

## 결과

### 장점

- 로컬 Docker Compose에서 실행하고 디버깅하기 쉽다.
- 검색과 모델 동작을 직접 이해하고 평가하기 좋다.
- 트랜잭션과 권한 규칙을 일관되게 적용할 수 있다.
- 필요가 확인된 워커나 어댑터만 나중에 서비스로 분리할 수 있다.

### 비용

- 모듈 경계를 코드 리뷰와 테스트로 지속적으로 지켜야 한다.
- 일부 작업을 독립 확장하려면 후속 분리가 필요할 수 있다.
- 한 저장소의 빌드 및 테스트 시간이 성장할 수 있다.
