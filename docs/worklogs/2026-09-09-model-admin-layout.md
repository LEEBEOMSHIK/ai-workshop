# 관리자 모델 화면 너비와 명시적 저장

## 문제와 수정

긴 모델 식별자와 표의 최소 너비가 페이지를 가로로 밀어냈고, 나란히 배치된
폼의 높이가 늘어나면서 짧은 폼의 버튼도 과도하게 커졌다. 자료 승인 컨트롤은
기존 폼 스타일을 상속하지 못했다. standalone 모델 관리자에만 CSS module을
적용해 줄바꿈·축소 가능한 그리드·내용 높이 기준 폼과 일관된 컨트롤을 제공한다.
표의 버전/상태 열을 줄이고 정의 열을 넓혔다. embedded 구성 화면 스타일은 유지한다.

정책 선택은 자동 저장하지 않는다. 버튼을 `정책 저장`으로 통일하고 미저장·저장 중·
성공·실패를 구분한다. 성공 응답의 실제 정책만 저장 기준으로 삼고 실패 시 입력과
이전 버전을 보존한다. 재편집 시 오래된 성공 안내를 지운다. 변경 없는 기존 정책의
중복 저장은 막되 첫 지식 공간 정책 저장은 허용한다. 공급자 허용 규칙과 API는 그대로다.
