# ADR-0006: 공개 연구소 입구와 Lab 작업 현장을 분리한다

- 상태: 승인됨
- 결정일: 2026-09-04
- 대체 범위: `ADR-0005`의 `/`·`/labs` 동일 화면 결정

## 배경

`/`와 `/labs`가 같은 `LabWorldPage`를 렌더링하면 두 URL이 서로 다른 탐색 단계를 제공하지
못한다. 프로젝트의 원래 사용자 흐름은 공개 첫 화면에서 돌아다니는 기술 관리자를 발견하고,
AI Labs로 들어간 뒤 각 연구실에서 관리자가 일하는 모습을 살펴보는 구조다.

## 결정

`/`는 공개 AI 연구소의 입구·랜딩을 담당한다. 공개 catalog의 기술 관리자를 `roaming`
상태로 보여주고, 캐릭터 소개의 첫 동작은 `/labs`로 연결한다.

`/labs`는 AI Lab 작업 현장을 담당한다. 공개된 각 기술 연구실의 장비와 `working` 상태
관리자를 보여주고, 캐릭터 소개 동작은 해당 `/labs/{slug}` 상세로 연결한다.

두 화면은 같은 검증된 공개 catalog를 사용하지만 페이지 조합과 사용자 동작을 공유하지
않는다. `/`의 canonical은 `/`, `/labs`의 canonical은 `/labs`로 각각 선언한다. 실제로
공개된 Lab만 표시하며 미래 Lab이나 도메인 이름을 화면 코드에 미리 고정하지 않는다.

## 결과

### 장점

- 연구소 발견, Lab 탐색, 기술 상세의 단계가 URL과 화면에서 명확히 구분된다.
- catalog 검증과 캐릭터 접근성 계약은 재사용하면서 중복된 페이지 경험을 없앤다.
- 이후 Lab이 추가돼도 같은 catalog를 통해 입구와 작업 현장이 함께 확장된다.

### 비용

- 입구와 작업 현장에 서로 다른 반응형 장면과 회귀 테스트가 필요하다.
- 같은 관리자가 두 맥락에서 다른 목적지로 안내하므로 캐릭터 동작을 명시적으로 주입해야 한다.
