# ADR-0002: 비공개 데이터는 로컬 우선으로 처리한다

- 상태: 승인됨
- 결정일: 2026-08-29

## 배경

자산운용 문서에는 비공개 정보, 개인 정보와 민감한 운용 정보가 포함될 수 있다. 공개 포트폴리오와 실제 문서 검색이 같은 데이터 저장소를 사용하면 의도하지 않은 노출 위험이 커진다.

## 결정

문서 원본, 파싱 결과, 임베딩과 검색 색인은 로컬 개발 환경 또는 승인된 사내 환경에서 처리하고 저장한다.

공개 전시실은 별도 데이터베이스와 저장소를 사용하는 독립 배포로 운영한다. 비공개 환경과 런타임 데이터 연결을 만들지 않는다. 승인 및 비식별화가 완료된 공개 패키지만 이동한다.

외부 모델 API는 공개 또는 비식별 데이터로 승인된 모델 프로파일에서만 사용할 수 있다.

## 결과

### 장점

- 공개 기능과 민감한 원본 사이의 데이터 경계가 명확하다.
- 모델별 데이터 반출 정책을 검증하고 감사할 수 있다.
- 공개 환경이 침해돼도 비공개 문서 저장소에 직접 접근할 수 없다.

### 비용

- 로컬 모델 실행과 저장소 운영에 개발 PC 자원이 필요하다.
- 공개 콘텐츠 이동을 위한 내보내기, 검토와 가져오기 절차가 필요하다.
- 외부 모델과 로컬 모델의 성능 비교에 데이터 정책 제약이 생긴다.
