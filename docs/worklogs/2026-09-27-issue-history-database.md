# 문제·개선 이력 DB 전환

## 구현

[승인 설계](../superpowers/specs/2026-09-27-issue-history-database-design.md)에 따라 Platform Issue History를 추가했다. 한글 카테고리, 문제와 누적 사건, 문서·불변 본문 버전, 정확한 버전 연결, 요청 멱등 기록과 최초 이관 기록을 기존 PostgreSQL에 저장한다.

관리 화면은 검색·필터·페이지 및 카테고리/문제/진행 기록/문서/버전/연결 관리를 제공한다. 파일 직접 읽기와 JSON 대체 응답은 제거했다. DB를 운영 정본으로 전환하고 최초 JSON은 보존한다. 첫 질문 기준 세션 생성 변경은 별도 미해결 작업이다.

## 본래 환경 적용

- 기존 체크아웃·DB·마스터 계정·자료를 유지했다. 새 환경·계정·DB를 만들지 않았다.
- 변경 전 백업: `.local-data/backups/20260927-issue-history-pre0051.dump` (2,755,191bytes). archive catalog 읽기 성공이며 별도 복원 환경을 만들지는 않았다.
- 본래 DB `0050_conversation_attachments` → `0051_issue_history` 가산 migration 적용.
- 8개 문제·8개 카테고리·6개 문서/버전·13개 사건·12개 연결 이관. 재실행 unchanged, ID/필드/사건/관계/본문 SHA-256 대조 verified.
- 최초 manifest: `1bc1ccd5ded61840961234dcb13907d6a82927fb6954e8557ae0b59b7c94c770`.
- 기존 users1/workspaces3/documents3/asset_versions3/rag_conversations1 유지. 검증 후 issue_commands0이며 합성 기록이 남지 않았다.
- 기존 API18000 재시작, 직접·프론트5173 경유 health200. 익명 관리 API401/no-store.

## 발견 및 수정

- Windows Alembic 직접 실행은 Proactor 이벤트 루프에서 DB 연결 전 실패했다. 기존 selector policy를 적용해 재실행했고 실행서에 명령을 남겼다.
- 독립 검토에서 문서 연결 변경이 과거 사건 스냅샷을 재귀적으로 포함하는 문제를 발견해 제외했다. 반복 연결 변경 회귀 검증으로 확인했다.
- 저장 후 다음 편집의 revision 갱신, 충돌 시 입력 보존·명시적 새로고침, 구 파일 문서 링크 재선택 안내를 보완했다.

## 검증

- 이관 사전검사 7건: 누락·경로·UTF-8·크기·중복·manifest 변경.
- 본래 DB 통합검증 4건: 멱등 요청·충돌·비활성 카테고리·필터/페이지, 버전 고정·관계, 원본 이관 대조, 두 연결 간 잠금 직렬화. 모두 통과했고 쓰기는 외부 트랜잭션 롤백.
- 최종 백엔드 단위19건·프론트 회귀42건 통과. Python 7파일 타입 검사, TypeScript 전체 타입 검사, 변경 영역 Ruff/ESLint 통과.
- 최초 통합 실행은 단위 테스트 임시 폴더의 Windows 권한 문제로 7개 setup 오류가 났다. DB 통합4건은 통과했으며 단위19건은 기본 권한 실행에서 재확인했다.
- 이관 통합 테스트는 이후 문서 수정에도 재실행 가능하도록 독립적인 합성 manifest를 사용하는 롤백 검증으로 보완했다. 실제 최초 입력 대조는 별도의 `--verify`로 완료했다.
- 브라우저 세션 만료로 로그인 화면에 도달했다. 사용자에게 기존 마스터 재로그인을 요청했으며 DB 전환 후 실제 화면 확인은 남아 있다. 이를 브라우저 검증 완료로 보고하지 않는다.
- 후속 2단계 카테고리 작업에서 마스터 로그인을 확인하고 DB 목록·필터·문서 버전 조회·관리 진입을 본래 브라우저에서 검증했다. 당시 미완료였던 조회 화면 확인은 완료됐으며 실제 관리 쓰기는 롤백 통합검증 범위다.

관련 문서가 이후 수정돼도 이관 당시 본문은 버전1로 보존된다. 변경된 원본을 최초 이관 도구로 덮어쓰지 않는다. 운영 복구는 이전 앱으로 돌아가고 새 DB 기록을 보존하는 방식이며 테이블을 자동 삭제하지 않는다.
