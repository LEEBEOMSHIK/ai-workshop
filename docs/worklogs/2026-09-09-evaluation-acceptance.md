# 기본값과 분리된 RAG 평가 통과 반영

날짜: 2026-09-09

## 문제와 변경

기존 평가 통과 반영은 전역 기본값 승격과 결합되어 있었다. 도메인에 연결하려는 정확한
구성 버전의 검색 평가를 반영하는 동작과, 전체 기본값을 바꾸는 동작을 분리했다.

owner 전용 `POST /api/v1/rag/configurations/{configuration_id}/versions/{version_id}/evaluation-acceptance`는
명시한 `evaluation_run_id`의 완료 결과와 불변 정책을 검증한다. 요청자·구성 버전·데이터셋 해시·
후보 모델 구성·답변 정책·지표/K가 일치하고 기존 PromotionGate를 만족할 때만 해당 버전을
PASSED로 변경한다. 기존 기본값 플래그는 모두 유지한다.

기존 DB 제약이 다른 성공 실행을 찾을 수 있으므로 새 경로는 **요청한 실행 자체**의 연결을
추가로 확인한다. 실패한 실행을 선택하면 다른 성공 결과로 대체하지 않는다. 동일한 정상
증거의 반복 반영은 멱등적이며, 구버전을 지정하면 최신 버전으로 바꾸지 않는다.

기존 기본값 승격은 공유 검증을 사용하며 별도 동작으로 유지한다. 새 migration이나 의존성은 없다.
API·스키마·서비스·저장소·도메인 역할을 분리했고 UI는 후속 작업이다.

## 검증

메인 재실행 및 독립 spec/quality 리뷰를 완료했다.

- 관련 구성·평가·도메인 단위/API 회귀: 138 통과, 기존 SQL 1건 제외, 기존 Starlette 경고 1건.
- 신규 격리 PostgreSQL: 22 통과. 모든 기본값 보존, 잘못된 실행 거절, 구버전·반복 요청,
  버전 생성과 경쟁 요청의 실제 잠금 대기를 검증했다.
- mypy: 구성 모듈 7개 파일 통과. Ruff: 변경 소스·테스트 8개 파일 통과.
- 기존 SQL 제외 사유: secret_key 설정 누락으로 DB 연결 전 실패. 해당 사례까지 검증됐다고
  주장하지 않으며, 이번 변경에서 기존 테스트나 인증·환경 설정을 수정하지 않았다.

SQL 테스트는 정확한 이름과 접속 DB를 검증하는 기존 격리 도구로 임시 DB만 생성·삭제했다.
합성 관측을 사용해 저장소 불변 조건을 검증했으며 실제 검색 또는 LLM 품질 측정은 아니다.
사용자 DB·문서·외부 전송 정책·모델 설정은 변경하지 않았다.

## 경계와 다음 작업

### 후속 백엔드 평가 작성 API 검증

같은 날 평가 작성 API도 구현·독립 리뷰를 완료했다. owner 전용
`/api/v1/rag/evaluation-authoring` 아래 `documents`, `preview`, `runs`를 제공한다.
본문 없는 문서 목록에서 대상을 고른 뒤, 권한이 있는 정확한 활성 버전의 전체 근거만 조회한다.
조회량이 한도를 넘으면 부분 결과를 성공으로 반환하지 않는다.

실행 요청은 수동 정답과 실제 근거 위치를 검증해 기존 평가 실행 경로에 연결한다.
저장 직전에 문서·권한·처리 구성·실제 색인 식별자를 다시 대조한다. 같은 작성 요청은
최초 스냅샷을 재사용하며 다른 내용으로 덮어쓰지 않는다. 명시적 재실행은 별도 실행을 만들 수 있다.

메인 재검증: 관련 회귀 217건, 격리 SQL 47건(신규 작성 25건과 통과 반영 22건),
mypy 8개 소스, Ruff 12개 파일 통과. 앞서 기록한 기존 SQL 1건 제외와 경고 1건은 유지한다.
실제 SQL 경쟁·취소 롤백을 검증했지만 검색 색인 확인기는 합성 대역이며 모델이나 worker를
실제로 실행한 결과는 아니다. 후보/BM25 처리·색인 불일치의 직접 거절 테스트 추가는
비차단 리뷰 보강 사항으로 기록했다. 거절 조건과 최종 스냅샷의 처리 구성 선택은 검토했다.

OpenAPI에서 프론트엔드 타입을 생성했고 관리자 작성 UI 연결도 구현·최종 독립 리뷰를 완료했다.
최종 전체 구성 화면 테스트 66건·타입·린트를 통과했다. 문서 목록과 근거 선택, 수동 질문·정답·
하이라이트, 명시적 첫 실행·정책 저장·정책 적용 실행과 별도 통과 반영을 제공한다.
탭 간 초안 보존, 재조회·재시도, 고급 비교와의 늦은 응답 충돌, 구버전 기본값·실험 배지를
검증했다. 직접 처리·색인 불일치 거절 6사례를 추가해 작성 SQL 31건도 재검증했다.
앞서 기록한 비차단 테스트 보강 사항은 해결됐다.

실제 private API(18000)만 최신 코드로 재시작해 health와 새 API 4개 등록을 확인했다.
프론트·공개 API·Docker와 사용자 데이터는 변경하지 않았다. 현재 브라우저는 세션 만료 상태라
로그인 이후의 실제 문서 업로드·평가·모델 동작은 아직 검증하지 않았다.

PASSED는 과거 검색 평가 증거의 반영이다. 현재 문서 준비 상태, 생성 연결 검사, 답변 품질,
외부 전송 동의 또는 도메인 활성화를 대신하지 않는다. 별도 영구 승인 감사 레코드는 만들지 않는다.

다음은 재로그인과 합성 자료 업로드 확인 후 실제 평가·Codex 답변·인용·후속 질문 검증이다.
아직 사용자 RAG 테스트 준비 완료로 판단하지 않는다.
