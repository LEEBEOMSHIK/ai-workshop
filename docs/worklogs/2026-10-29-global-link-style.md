# 전역 링크·선택 스타일 정돈

사용자는 상단 탐색 링크 수정 후에도 비교 회차 선택 등에 밑줄이 남았다고 지적했고 전역 조사를 요청했다. 앞선 상단 한정 변경에서 범위를 넓혀 일반 UI 링크·선택의 상시 밑줄을 제거했다. 원문 근거의 정확 일치·문맥·의미를 나타내는 선은 장식과 구분해 유지한다. 기존 다크·청록, URL, native anchor/radio/tab, 키보드, 답변·인용·모델 설정과 데이터를 보존했다.

## 범위와 책임

중간 위험의 공통 UI 변경으로 프론트 구현과 문서 역할, 독립 리뷰를 분리했다. root는 링크 기본값·실행/도메인 표시·실제 UI 검증·기록을 통합하고, 선택 구현 담당은 ChoiceGroup·모델/평가 탭과 기존 브라우저 하네스의 오래된 밑줄 assertion만 수정했다. 문서 담당은 디자인 시스템 정본을 갱신했다. 독립 리뷰는 제품을 수정하지 않고 전역 누락·specificity·구조형 링크 회귀를 확인했다. backend/DB/모델/권한 계약 변경이 없어 해당 구현 역할은 제외했다.

- `shared/ui/links.css`: native 링크의 기본 밑줄 제거, 일반 텍스트 링크는 작은 표면·경계로 식별, 독립 이동은44px, 포커스 유지. class가 있는 카드/조작 링크는 기능 소유 스타일을 따른다.
- ChoiceGroup segmented·모델 탭·평가 상위/내부 탭: 선택 배경·경계·체크 도형. 체크는 빈 CSS pseudo-element이므로 접근 가능한 이름을 변경하지 않는다.
- 파일함 현재 메뉴·실행 현재 턴·에이전트/위임 선택: 밑줄 대신 선택 표면·경계·강조 문구. 기존 native 상태 유지.
- 비교/실행 상세·원문·새로고침 링크: 밑줄 대신 클릭 가능한 표면·경계.
- sidebar·흐름도 메뉴·공개 페이지 이동·대화 턴·파일함 구조형 링크: 전역 inline 표면이 비선택 구역에 번지지 않도록 명시 초기화. 독립 리뷰에서 발견해 통합했다.
- 전역 CSS 검색의 남은 positive `text-decoration: underline`은 `mark.keyword-highlight` 1곳이다. 검색 일치 범례, 문맥/의미 점선·실선, 시간 미기록 막대, 표·헤더 구분선과 픽셀 장면 구조는 보존했다.

정본: [UI 스타일](../guidelines/ui-style-guide.md#화면-이동-링크), [선택·탭](../guidelines/ui-style-guide.md#choicegroup탭포커스), [적용 목록](../guidelines/design-system-coverage.md#2026-10-29-전역-밑줄-스타일-정리). ISSUE-00040에 후속 기록을 추가했다.

## 실제 확인과 자동 검증

- 본래 비교: 회차 첫 요청→반복 방향키 전환, 선택 체크1/비선택0, 밑줄 없음,44px,가시적 포커스. 저장 답변의 회차 전환 유지. 실제 선택 텍스트/배경 대비8.52:1.
- Chrome viewport320/375: 비교 document client/scroll305/305·360/360px, 일반 조작 요소 underline0, label44px. 이후 viewport 복원. 실제 모바일 장치 검증은 아니다.
- 본래 모델:5탭46.39px,방향키 전환·체크·밑줄 없음. 비선택 sidebar는 투명 배경·추가 그림자 없음.
- 본래 평가:상위3/내부3탭44px·반경10px·체크,저장된 평가의 근거·진단 전환·기존 답변/인용2건·실행 상세 연결 확인. 인용 링크는 표면·경계 있고 밑줄 없음.
- 본래 실행:저장 답변·인용·처리 단계 유지,조작 밑줄0/페이지 가로 넘침0. 학습은 기존 빈 상태 표시 확인.
- 선택 관련5파일64개와 확장53파일395개 Vitest 통과(별개 범위). 확장 범위는 실행·비교·탐색·문제 이력·학습·공개 화면이다. 설치된 `node node_modules/vitest/vitest.mjs run ... --pool=threads --maxWorkers=1` 사용,설치 없음.
- 전체 TypeScript,하네스 node 문법검사·ESLint,ChoiceGroup TSX ESLint,전체34CSS 파싱·독립 리뷰·diff 검사 통과. 낮은 영향의 스타일을 복제하는 새 단위 테스트는 추가하지 않고 기존 UI 동작 회귀와 실제 CSS 렌더를 구분했다.

개발 HMR에서 제거한 옛 선언이 잠깐 남아 실제 computed underline이 관측됐으나 새로고침 뒤 최종 CSS에서 사라짐을 확인했다. 소스 수정만으로 성공을 처리하지 않았다. 공개 연구 목록은 기존 서비스 조회 오류로 실제 콘텐츠 확인이 제한됐으며, 이번 작업에서 reader 기동이나 자료 변경을 하지 않았다. 공개 회귀는 코드/mock 검증이며 실제 공개 콘텐츠 수용으로 확대하지 않는다. 모든 화면의 모든 상태·실기기 수용을 주장하지 않는다.
