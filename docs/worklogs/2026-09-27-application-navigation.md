# 전체 화면 공통 탐색 적용

- 날짜: 2026-09-27
- 관련 문제: ISSUE-00010
- 상태: 구현·자동 검증 완료, 기존 계정 재로그인 후 작업소 화면 확인 필요

## 배경과 범위

앞선 관리자 메뉴 개편은 관리자 내부에만 적용되어 공개 화면과 작업소의 탐색 방식이 달랐다.
사용자 지적에 따라 공개 전시실, 게임 입구, 로그인, 비공개 작업소와 관리자를 공통 셸로 연결한다.
PC 사이드바와 모바일 모달 메뉴, 현재 위치 표시를 통일하고 각 영역의 권한에 맞는 메뉴만 제공한다.
기존 URL, 계정, 자료와 문제 번호는 유지한다. 별도 환경이나 테스트 계정은 만들지 않는다.

## 구현과 검증

공통 메뉴 구현, 공개 화면 연결, 독립 권한/코드 검토를 분담한다.
작업소 본문은 사이드바를 제외한 가용 폭에 반응하고 대화 영역은 공통 상단 바의 실제 높이를 사용한다.
공통 ApplicationShell로 공개·작업소·관리자를 연결하고 기존 중복 메뉴 CSS를 제거했다.
로그인·초기 설정 및 API 오류 화면도 같은 메뉴를 유지한다. 게임 전용 헤더는 공통 메뉴로 대체했다.
초기 설정·학습·파일함의 중복 화면 높이를 보정하고 파일함·학습·대화에 가용 폭 기준 반응형 배치를 추가했다.

### 검증 결과

- 공통 메뉴 및 양쪽 레이아웃 62건 통과, 미저장 보호 추가 후 공통 셸 9건 재검증 통과.
- 독립 권한/메뉴 테스트 7건 통과. 공개 인증 호출·계정 정보 비노출, 회원 관리자 메뉴 비노출 확인.
- 공개 화면·로그인·초기 설정·게임 후속 42건, 최종 대상 17건 통과(중복 포함).
- 초기 공개/게임 범위 실행 중 변경된 메뉴와 목록을 구분하지 못한 테스트 2건 실패. 범위를 명확히 고친 뒤 해당 테스트 포함 후속 검증 통과.
- 작업소·학습·도메인 파일함·대화·세션 90건 통과.
- TypeScript·대상 ESLint 및 독립 코드 검토 통과.
- 본래 Chrome 공개 목록·RAG·공개 연구 오류 화면의 390px 폭에서 가로 넘침 없음.
- 모바일 메뉴의 실제 모달 상태·게임 캔버스 포커스 해제·Escape 후 버튼 복귀 확인.
- 게임 입구: 390×844에서 캔버스390×788, 1100×800에서 캔버스860×740. 본문 높이와 가로 넘침 없음.
- 공개 연구 조회는 현재 서비스 오류 화면으로 표시되어 성공 목록의 실제 데이터 검증은 미완료. 오류 상태의 공통 메뉴는 확인.
- 기존 브라우저 인증이 만료되어 작업소 진입 시 로그인으로 이동했다. 사용자의 기존 계정 재로그인을 요청했으며 실제 비공개 화면 재검증은 대기 중이다.
- 별도 계정·DB·환경을 만들거나 기존 자료를 변경하지 않았다. 실제 모바일 기기 검증은 포함하지 않았다.

## 이력

ISSUE-00010의 관리자에 한정된 적용 범위를 전체 화면으로 확장했다.
앞선 관리자 검증 기록은 보존하고 이번 후속 문서를 별도로 연결한다. 실제 작업소 재검증 전까지 상태를 implemented로 기록한다.
