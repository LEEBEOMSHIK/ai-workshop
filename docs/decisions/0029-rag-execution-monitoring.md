# ADR-0029: RAG 실행 메타데이터와 현재 권한 기반 모니터링

- 상태: 승인됨, 2026-09-28
- 근거: [승인 설계](../superpowers/specs/2026-09-27-rag-execution-monitoring-and-evaluation-design.md)

RAG가 서버 실행 ID, 제한된 단계·점수·원문 위치·구성 참조를 소유한다. 본문 정본은 기존 turn/평가 결과다. 별도 본문, 프롬프트, 공급자 원문 오류를 복제하지 않는다.
기존 요청 진단의 영속화 금지에서 이 형식의 메타데이터만 예외로 승인한다. 반환 top_k 및 기록 상한 200개 안에서 후보를 저장하고 잘림 여부를 기록한다. 이 상한은 검색/선택 결과를 변경하지 않는다.
대화 종료와 실행 종료는 같은 트랜잭션에서 조정하며 종료 상태를 역전하지 않는다. 관측 실패는 원래 오류를 대체하지 않는다.
관리자는 자신의 실행만 조회하고 현재 원문·이전 대화 의존성을 먼저 확인한다. 목록·검색·집계에 같은 권한을 적용한다. 과거 기록은 확인 가능한 필드만 읽으며 재실행/가짜 backfill을 하지 않는다.
외부 correlation ID는 참조 정보일 뿐 식별·권한 조인 키가 아니다. 기존 감사 기록은 nullable 실행 FK로 신규 실행부터 연결한다.
