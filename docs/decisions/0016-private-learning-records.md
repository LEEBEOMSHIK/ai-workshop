# ADR 0016: 비공개 학습 기록과 기술 참조를 분리한다

- 상태: 승인·코드 반영 및 자동 검증 완료, 개발 DB 활성화 별도
- 기준일: 2026-09-07
- 상세 계약: [학습·서비스 연결](../superpowers/specs/2026-09-07-learning-service-link-design.md)
- 실행 계획: [비공개 Learning 1단계](../superpowers/plans/2026-09-07-private-learning.md)

## 결정

Platform Learning이 사용자 소유의 자유 메모와 구조화 실험을 저장한다. 기술 주제와 전문
도메인은 별도로 분류하고 RAG나 파인튜닝의 실행 결과를 학습 기록 안에서 생성하지 않는다.
기록의 변경은 불변 revision을 남기며 예상 revision과 현재 revision이 다르면 409로 거부한다.
1단계 수명주기는 보관·복원이며 영구 삭제 API는 제공하지 않는다.

기술별 대상은 일반 참조 계약과 조립부 resolver로 연결한다. Platform에서 RAG 구현을
import하지 않으며 기록 소유권은 참조 대상의 권한을 추가하지 않는다. 연결·조회·과거 revision
조회에서도 현재 대상 권한을 확인한다. 비허용 대상의 제목·본문·링크는 반환하지 않는다.

비공개 API는 로그인 사용자의 소유 기록만 다루고 owner 역할에도 타인 기록 우회를 주지 않는다.
메모 본문은 우선 plain text로 표시해 HTML 실행·외부 이미지 자동 요청을 만들지 않는다.
공개 snapshot, 공개 캐릭터 연결, 모델 실행과 수동 학습은 별도 단계다.

### 평가 참조 표시 보완

같은 상태의 평가 실행을 사용자가 구분할 수 있도록 기존 소유자 전용 RAG 평가 응답에
저장된 `created_at`을 추가한다. DB의 기존 생성 시각을 전달하며 현재 시각이나 가짜 이름으로
대체하지 않는다. UI는 상태·생성 시각을 표시하고 동일 표시값의 목록 내 구분만 추가한다.
타인 실행 조회 정책, 평가 알고리즘·프로파일·DB 스키마는 변경하지 않는다. 식별 정보가 없는
임의 UUID 표시명이나 가짜 상세 경로를 만드는 대안은 사용하지 않는다.

## 결과

- 기록은 여러 기술에 연결할 수 있지만 공개 여부와 서비스 준비 상태를 혼동하지 않는다.
- 영속 revision·동시 수정·참조 권한 회수는 테스트 가능한 별도 계약이다.
- 기존 개인 자료를 자동 가져오기·공개·학습하지 않는다.
- 공개·외부 전송·훈련 승인 경계와 Codex CLI의 기존 차단 결정은 변경하지 않는다.
