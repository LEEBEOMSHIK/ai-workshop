# ADR-0003: BM25와 bi-encoder의 hybrid retrieval을 기준선으로 사용한다

- 상태: 승인됨
- 결정일: 2026-08-29

## 배경

자산운용 문서 검색에는 조항, 상품명, 코드와 수치의 정확한 일치와, 원문과 다른 표현으로 묻는 의미 질의를 모두 처리해야 한다. Dense retrieval만 사용하면 정확한 문자열 검색의 기준선을 잃고, BM25만 사용하면 의미가 같지만 표현이 다른 문서를 놓칠 수 있다.

검색 모델, 리트리버, 리랭커와 LLM을 한 프로파일에 섞으면 어느 구성요소가 품질을 개선했는지 평가하기 어렵다.

## 결정

첫 AI 검색은 다음 기준선을 사용한다.

```text
BM25 retrieval + bi-encoder dense retrieval + RRF
```

BM25 단독 결과를 항상 비교 기준으로 유지한다. 임베딩 및 청킹 변경은 색인 프로파일, 검색 결합과 리랭커 변경은 검색 프로파일, LLM과 프롬프트 변경은 생성 프로파일로 분리한다.

첫 검색 순위에는 LLM을 사용하지 않는다. 리랭커와 생성 LLM은 hybrid 기준선이 평가된 뒤 독립 실험으로 추가한다.

## 결과

### 장점

- 정확한 용어 검색과 의미 검색을 함께 제공한다.
- BM25 대비 각 모델의 개선 폭을 측정할 수 있다.
- 임베딩, 검색과 생성 실험의 책임과 재색인 조건이 명확하다.
- 검색 결과와 의미 하이라이트를 LLM 답변과 독립적으로 검증할 수 있다.

### 비용

- 문서와 질의에 대해 둘 이상의 검색 경로를 운영해야 한다.
- 임베딩 모델별 색인 저장 공간이 필요하다.
- RRF와 후보 수를 실제 평가 세트에서 조정해야 한다.
